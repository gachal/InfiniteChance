# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

浏览器 SPA(Vue3 + vue-flow);Wails v3 桌面壳是同一 SPA 的原生包装(画布主窗),不改变 web 设计语言。移动端浏览器不是目标形态。

## Users

单一用户 = 作者本人(兼唯一管理员)。私人创作场景:无注册、无支付、无多租户、无协作。登录是单管理员 JWT 会话,首次初始化引导(`POST /auth/init`)之后不再出现。

## Product Purpose

无限画布创作工具:在自由画布上编排 AI 创作流水线——提示词(Agent 节点/技能)、生图(含图生图、透明背景)、生视频(首尾帧/参考图·视频·音频)、媒体分析;节点连线形成迭代链,产物以素材形式自有持久化、跨画布复用。成功标准(用户确认):长期日用的私人创作主力工具,值得持续打磨细节与体验。

## Positioning

与自家 LLM Token 网关(OpenAI 兼容中转)同仓一体:上游渠道、调度熔断、双轨计价都在网关侧,画布只面对公开模型与任务编排;成本透明(微美元计价、用量审计可对账),素材永久自有(本地卷/OSS/COS,不依赖厂商约 24h 的临时 URL)。三条创作线并重(用户确认):生图迭代、视频创作、Agent 提示词工程,不分主次。

## Operating Context

- 主战场(用户确认):浏览器——Docker 栈 `:8091` / dev `:5174`(`make dev-canvas`);Wails 桌面壳为备选形态(SQLite 单机装配,数据与 Docker 栈互不通用)。
- 创作主线多线并重:提示词 → 图 → 参考迭代;文/图生视频(首尾帧、参考多媒体组合);技能生提示词、视频反推、携媒体多轮分析。
- 画布交互范式:节点(agent/图片/视频/分析)+ 两击连线(左 `+` 接上游、右 `+` 连下游);生成对话框贴选中媒体节点出现(图片/视频双模式、草稿按模式独立、发送后草稿保留);侧滑面板(素材/生成记录/Agent 历史);媒体节点点击媒体区开灯箱全屏预览。
- 整图 JSON 自动保存;画布任务持久在库,浏览器关闭后任务照跑,重开回写节点。
- admin-web 是同产品的另一前端(渠道/计价/素材/审计管理);画布侧只读消费模型目录(`/image-models`、`/video-models`、`/prompt-models`)、技能目录与素材面。

## Capabilities and Constraints

- 硬性约束(违反即 bug;完整清单以 AGENTS.md「硬性约束」为准):画布前端不持任何密钥,调网关一律走 canvas/server 服务级 key;`data:` URI 进不了网关媒体契约;上游产物 URL 临时(约 24h),任务成功即转存自有存储;未配价模型一律拒绝,无静默兜底;素材对象键三分归档(`canvases/`、`uploads/`、`relay/`)。
- 全部领域语义(节点/连线/生成对话框/画布任务/技能/反推/分析/灯箱等)以 CONTEXT.md 为权威术语表;术语冲突以较新决策票为准。
- 明确不做:注册/支付/多租户、通用 Agent 运行时(即梦式任务列表、独立悬浮 composer)、管理台全局生成记录页。

## Product Principles

1. 单用户自用是特性不是局限:不为假想的多人场景增加复杂度。
2. 产物永久自有:一切生成结果落自有存储,可审计、可复用、可带走。
3. 成本透明可对账:每次调用有价可依、有流水可查,不静默兜底。
4. 画布即工作台:三条创作线在一张图上闭环,提示词与产物永久配对。
5. 先票后码:领域语义变化必须回写 CONTEXT.md,决策可追溯。
