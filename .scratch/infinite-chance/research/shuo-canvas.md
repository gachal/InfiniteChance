# SHUO-Canvas 调研纪要(2026-11-01)

> 用途:71 号票(元素参考生视频,grilling 中)的参考依据,以及后续候选池。对象:[ashuoAI/SHUO-Canvas](https://github.com/ashuoAI/SHUO-Canvas)。

## 1. 来源与可信度

- **仓库零源码**:git 树只有 README、LICENSE、COMMERCIAL-LICENSE.md、VERSION.txt、release_notes.txt(v0.0.5→v0.8.11 全量更新日志)与 14 张展示截图;Releases 只发 Electron 安装包(Windows exe、Mac arm64 dmg,electron-updater)。
- **闭源 + 双许可**(AI CanvasPro Dual License):非商业可查看/运行/修改,任何商用须书面授权。**只借鉴产品形态,不借代码。**
- 下文 SHUO 侧内容全部属「仅文档/更新日志可见」,实现细节(请求参数形状、连线逻辑)无从验证。

## 2. 与「N 个元素整合成视频」相关的形态

- **没有**「登场/耍帅/双人/同框/对决」类专门功能或提示词模板(全库检索 0 命中)。
- 底层能力是通用的**多参考图(±音频)直出视频**:视频节点左侧「入参槽」连线任意多个素材节点即挂参考,上限随模型(如 MiniMax H3:最多 9 张参考图 + 3 段参考音频;SD2.0/2.5 某渠道:最多 9 张参考图、不支持参考视频/音频)。
- 入参槽**不分元素类型**;分类发生在素材侧:「素材加入画布时按人物、场景、道具分列,并将同一素材的形象和声音参考整理成组」(v0.8.11)。
- **指代**统一走 `@节点名`:「之前是 @图片1 @图片2 现在改成 @节点的名字」(v0.5.3);「粘贴含 @素材名称 的提示词时,自动绑定可唯一匹配的素材」(v0.7.14)。
- **提示词辅助**:`/` 插入预设(内置「故事板分镜」8 个 + 自定义预设);替换工作室「AI 提示词增强」、复刻「AI 调整」(先出候选再采用);剧本工作室按目标模型格式(Seedance 2.0/2.5、Wan、MiniMax H3)生成分镜提示词并管理素材引用。
- 没有「先合成同框首帧再图生视频」的自动链;有宫格(4/9/16/25)、拼图、抠图/自动识别主体、RunningHub 工作流「人物全角度 V4」(一次 15 张多视角)等手工预制件。

## 4. 候选池(按价值排序,71 号票定案后逐个 grilling)

1. **多镜头拼接成片**(剪辑节点):把多段生成视频按序拼成一段,cut 序即拼接序;是「N 个镜头 → 成片」的自然下一步。
2. **分镜批量生成 + 分镜提示词按目标模型格式重写**:逐 cut 批量出画面/视频(须守「花钱操作人工确认」——批量 = 一次确认 N 笔,口径待定),提示词按 Seedance / MiniMax / 万相官方写法分别格式化。
3. **视频分析 → 分镜板导入**(复刻链第一步,53 号票「读方向导入」另票)。
4. **宫格切分 / 拼图**:一张多视图设定图拆成 N 张,或 N 张拼成一张参考 sheet(省参考额度)。
5. **Vidu 原生渠道**:`subjects` 主体一级概念(名称 + ≤3 图 + 音色,≤7 个,提示词 `[@主体名]`),最贴「元素」语义且最便宜;需新 adaptor + 网关 references 契约扩展。
6. **百炼加挂万相 3.0 / 2.7-r2v**:同一 video-synthesis 端点;2.7 允许首帧 + 参考联用、每个素材可绑 `reference_voice`;media 条目类型是否与 MiniMax-H3 同名待核(不同则 dashscope adaptor 要按模型分支)。

**核实状态**

- **人工核对官方原文**(方舟「创建视频生成任务」API,2026-11-01):「图生视频-首帧、图生视频-首尾帧、全模态参考生视频(包括参考图、视频、音频)为 3 种互斥场景,不可混用」;「全模态参考生视频可通过提示词指定参考图片作为首帧 / 尾帧,间接实现『首尾帧 + 全模态参考』效果」;`generate_audio` 缺省 true(模型基于提示词与画面自动生成同步人声、音效与背景音乐)。
- **调研 agent 引官方、人工未能复读**(方舟提示词指南页正文为 JS 渲染):「图片N」指代、「张三@图片1」绑定写法、超过 4 人稳定性下降。
- **未证实**:二手资料称 Seedance 提示词里 `【】` 表字幕(另有资料称台词用引号、字幕直接描述),互相矛盾——对 69 号票风格段「【画面风格】」有潜在影响,列为 71 号票真 key 验证点。
