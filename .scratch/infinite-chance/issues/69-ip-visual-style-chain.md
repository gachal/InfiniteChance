# 69 IP 画面风格链(企划级风格定位与生成注入)(2026-11-01 grilling 定案)

Type: feat
Status: planned(2026-11-01 grilling 定案,未实现;**先行于 70 号票**——设定图生成与分镜预填消费本票风格字段)

## Question

剧本全链(63-67)落地后,「剧本→分镜→生图」链路上没有任何画面风格定位:剧本节点、`save_script`/`save_storyboard` 工具 payload、导演系统提示词里都无风格概念;分镜逐张生成画风各异,70 号票的角色三视图也没有风格锚。需要定案:风格存在哪一层、由谁定、注入到哪些生成路径。

## 定案(2026-11-01 grilling)

1. **风格载体 = IP 级字段**:`ips` 表双方言加可空文本列 `style`(TEXT;EnsureSchema + 幂等加列迁移照 voice_id 先例)。IP 是跨媒介开发单元,风格是企划属性——大纲画布/每集画布/角色设定图同 IP 共吃一份;空值 = 无风格注入,存量行为逐字节不变。53 号票推迟的「风格指南」大文档节点维持推迟:字段管一句话风格,节点管长文档,不冲突。
2. **谁定 = Agent 提议 + 手动并存**:IP 编辑对话框(IpDetailView)加风格文本输入(手动兜底);剧本导演系统提示词(`internal/promptgen/agentdirector.go`)加纪律——IP 未定风格时,在剧本创作过程中**主动向用户提议画面风格**,经用户确认后调新工具落库;已定则遵循、不越权改。
3. **新 Agent 工具 `set_style`**(`internal/agenttools`,写 ips.style):库表类后端直写,ADR 0006 范式同 `create_character`;校验目标 IP = 当前画布所属 IP;幂等可覆盖(用户确认即写,改风格走手填或再次确认)。工具循环的领域工具注册表随之 +1。
4. **导演上下文注入**:工具循环系统提示词带入当前画布 IP 的风格文本(agentstream/agentloop 读 ips 行;空 = 不带该段)。让导演「有则遵循、无则提议」可执行。
5. **注入面(Q7=A)**:
   - **自动注入三条直通生成预填**(拼固定标记的风格段,建议形状「【画面风格】…」放 prompt 前部,随提交落任务行可审计):① 角色设定图生成(70 号票消费)② 分镜 cut 画面直通生成(`buildCutFramePrompt`)③ cut→视频直通(`buildCutVideoPrompt`);
   - **composer 显式开关**:生成对话框图片/视频模式加「带 IP 风格」复选框,**默认关**——手写 prompt 不被偷改,想带就勾;开关状态进各模式独立草稿(37 号票透明背景开关范式);IP 未配风格时开关不显示;
   - Agent 聊天注入**不动**(52 号票角色注入规则、技能模板均不受影响)。
6. **边界**:风格指南/世界观圣经等大文档节点维持 53 号票推迟;cut→变体精确绑定另票;本票不含任何「生成」本体——只管风格的定义与拼装,生图动作全在 70 号票与既有直通路径。

## 验证点

- 双方言加列迁移:存量库启动自愈加列,存量 IP style 为空、行为不变;`make test` 双方言集成测试绿。
- set_style 工具:Agent 循环内调用写库成功、越权 IP 拒绝、对话内确认流程(未定→提议→确认→落库→后续轮遵循)走通;工具调用不进持久会话历史(63 号票纪律)。
- 注入对账:三条直通路径预填 prompt 风格段逐字来自 ips.style;无风格时不拼不显示;composer 开关开/关发送的任务行 prompt 有/无风格段(生成记录面板可查)。
- 改风格即时生效:IP 编辑改风格后,下一次预填即用新值(目录按请求读表先例,无缓存)。

## Out of Scope

- 风格预设枚举/风格库(自由文本先行);风格指南大文档节点(53 号票推迟维持)。
- Agent 聊天(角色 chip/技能生成)的风格自动注入。
- 生成动作本体(见 70 号票);视频/音频链路的风格注入(未涉及)。
