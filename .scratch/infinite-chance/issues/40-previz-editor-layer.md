# 40 预演台编辑层:编辑撤出画布卡片

Type: grilling
Status: implemented(2026-10-06 实现;2026-10-05 grilling,Q1/Q2 用户拍板,Q3–Q5 推荐收口经用户「开工」确认)

## Question

39 号票实现后实际使用发现:预演台节点卡片把全部 3D 编辑内联在 340×220 的小卡片里,与画布操作冲突——视口吞掉滚轮与左/右键拖拽(`.stop` 隔离),画布平移/缩放手势在节点区域失灵;视口外的检查器滑杆等控件无 `nodrag` 标记,拖动连节点一起被 vue-flow 拖走;在如此小的视口里排机位、拖 gizmo 也根本不够用。改为:**添加后点击进入专门的全屏编辑页修改**,画布卡片收拢为纯展示。

## Answer

1. **形态 = 编辑器内全屏编辑层(Q1,用户拍板)**:灯箱/生成对话框同族范式([ADR 0002](../../../docs/adr/0002-composer-paradigm.md)),Teleport 到 body 铺满全屏,顶部「返回画布」按钮 + Esc 双路等价退出;打开时全屏遮挡,画布不响应交互。画布视图**不卸载**——返回即原位(视口/缩放/选中态零丢失)。场景改动继续走既有 scene-change → `updateNodeData` → autosave(800ms 防抖 + 版本乐观锁)链路,编辑层只是另一个触发者,退出后防抖照常落盘,无丢草稿窗口。否决独立路由页(`/canvas/:id/previz/:nodeId`):画布卸载重载、视口/选中态全部重置、防抖中跳转需额外 flush 保障,收益只有深链(单用户场景价值趋零)。

2. **卡片 = 帧卡(Q2,用户拍板)**:卡片不再跑 three.js——移除节点内实时视口与常驻 RAF/WebGL 上下文(消除多预演台节点挤爆浏览器 WebGL 上下文上限的风险),预演台区域的手势全部还给画布。卡片显示**最新渲染帧**(响应式随渲染回写更新);无帧时空态占位,文案「点击进入排练」自解释入口。按钮只留**落画布**(stopPropagation,不触发进入)。渲染、机位下拉、检查器滑杆、添加行全部移入编辑层。观感与媒体节点一致。

3. **进入 = 整卡点击(Q3,推荐收口待复核)**:点卡片任何位置(「落画布」按钮除外)打开编辑层——最大命中区给高频动作。39 号票兑现的「帧点击开灯箱」(33 号票「留口待挂入口」)**在预演台上修订**:灯箱入口收进编辑层(渲染完成即可看帧大图,编辑层视口本就近全屏,画布侧灯箱价值很低);33 号票对图片/视频节点的灯箱行为不变。CONTEXT.md「媒体预览灯箱」词条「范围仅媒体节点」的表述随之修订为不含预演台。

4. **编辑层内部 = 现有能力整体搬迁,不新增不削减(Q4,推荐收口待复核)**:全屏 3D 视口为主体;OrbitControls(左键轨道/右键平移/滚轮缩放)+ gizmo 平移 + 点选逻辑原样保留,只是空间放大。面板承载:对象添加(+盒/柱/板/人形)、对象/机位列表与选中、检查器(旋转/缩放滑杆、机位 FOV、删除)。顶部工具条:返回、机位切换、**渲染**(当前机位出帧,链路不变:`toBlob` PNG → `/api/assets/upload` → 写回节点 `latest`)、**落画布**。`PrevizStage.vue` 升级为尺寸自适应组件复用(`ResizeObserver` 已支持,全屏天然适配),节点卡片用法移除。编辑层编辑器级单实例,同时只绑一个节点;层内选中态属 UI 态不入节点 data,重开回默认。

5. **文档回写(Q5,推荐收口待复核)**:CONTEXT.md「预演台节点」词条修订(卡片 = 帧卡、编辑承载 = 全屏编辑层、「媒体区可点灯箱」表述改为「灯箱入口在编辑层」);不立新 ADR——交互承载变更不是架构取舍,且是 ADR 0002 范式的又一次应用,本票即决策记录。

## 显式 out of scope

预演台领域能力零变化:姿势/灯光/关键帧/glTF 导入/多机位批量出帧(39 号票清单继续有效);编辑层不加新编辑能力(对象/机位改名、多选、撤销重做等不做,现有能力原样迁);生成对话框、连线矩阵(previz→image)、计费生态零改动;场景数据结构与持久化零改动(节点 data 原样)。

## 产出面

- `canvas/web`:新增 `PrevizEditorLayer.vue`(全屏编辑层,Teleport,ADR 0002 同族);`PrevizStage.vue` 改造为尺寸自适应编辑组件;`PrevizNode.vue` 收拢为帧卡(帧/空态 + 落画布);`CanvasEditorView.vue` 接线(开层、渲染回写、落画布原逻辑保留)。
- `packages/api`:零改动。
- **后端零改动**。

## 验证点

卡片点击进层、Esc/返回按钮退出且画布视口/选中态原位;空态占位与渲染帧展示、落画布按钮不误触进入;编辑层内摆台 → 渲染 → 帧回写卡片 → 落画布全链;画布手势在预演台卡片区域恢复(滚轮缩放/拖拽平移不再被吞);多预演台节点零 WebGL 上下文常驻;33 号票灯箱对图片/视频节点不变;`make test` + `make lint` + 前端构建 + dev 实际点验。
