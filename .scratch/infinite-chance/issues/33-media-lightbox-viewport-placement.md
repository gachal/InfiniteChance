# 33 媒体节点灯箱预览 + 新建节点视口落点

Type: grilling
Status: approved(2026-10-03 grilling 定案;同日实现)

## Question

两则画布 UX:1) 图片/视频节点的产物在节点里只有缩略展示,看细节得下载;视频节点内联 `<video controls>` 在 220px 卡片里进度条不可用。点击节点媒体区直接看大图/大片的交互怎么定?2) 工具栏添加与素材插入的新节点落在写死图坐标 `{140+step, 120+step}`,画布平移缩放后新节点出现在视口外,怎么改?

## Answer

1. **点击媒体区直开灯箱(定案)**:图片/视频节点点击媒体区直接打开全屏灯箱,两节点交互一致。视频节点去掉内联 controls,改静音无 controls 的首帧缩略 + 播放图标叠加——播放集中到灯箱(自动播放、有声、完整 controls;点击打开即用户手势,浏览器放行有声自动播放)。选中行为保留:点击仍选中节点,关闭灯箱后生成对话框原样在。

2. **灯箱形态(纯展示档)**:编辑器级单实例全屏浮层(Teleport 到 body,生成对话框同族范式,ADR 0002),深色遮罩;媒体等比适配居中,放大到撑满视口为止、不缩小超过原尺寸;**不做缩放平移**(真痛点出现再立票)。图片右上角下载按钮(复用 `<a download>`);关闭 = Esc / 点击遮罩 / 右上角 ×,三路等价。

3. **触发边界**:拖拽节点不触发(vue-flow click 语义天然区分);空占位、「素材不可用」、任务在途/失败态不触发;data: URI 历史产物同样可预览(`<img>`/`<video>` 直接吃)。

4. **范围 = 仅图片/视频节点**:素材面板、生成记录面板、Agent 历史面板的缩略不接入;灯箱组件按可复用形态留口,将来挂入口即可。

5. **新建节点落点(视口中心)**:改三处无锚点落位——工具栏添加(`addNode`)、素材插入与生成记录「插入画布」共用的 `insertAssetRef`——新节点落当前视口中心(`screenToFlowCoordinate` 换算),级联偏移保留(连加多个不错叠)。**有锚点的落位一律不动**:生成产物(+320)、反推/分析(+260)相对源节点偏移的路径维持现状;工具栏添加后的自动选中行为不变(24 号票对话框锚点依赖)。

6. **显式 out of scope**:灯箱缩放/平移/多图切换、面板缩略接入灯箱、后端改动(素材 content 端点现成,零服务端工作)。

7. **产出面**:`canvas/web`(MediaLightbox 组件、ImageNode/VideoNode 接入、编辑器落点换算提纯函数 + vitest);CONTEXT.md 新增「媒体预览灯箱」词条、「节点」词条补交互一句。

8. **验证点**:`make test` + `make lint` + `pnpm --filter canvas-web build`(vue-tsc);dev 打开画布实际点验——图片点击开/关、视频灯箱有声播放、拖拽不误触、平移缩放画布后新建节点出现在眼前、灯箱打开时生成对话框被遮罩盖住且关闭后还原。
