# 24 视频生成对话框(全模态参考 + 首尾帧)

Type: grilling
Status: approved（2026-09-30 grilling 定案,待实现）

## Question

视频生成收进生成对话框范式(21 号票遗留清单明列「图生视频表单收进对话框」):视频模式怎么同时支持文生视频与图生视频?参考图之外,首尾帧与参考视频/参考音频(对齐即梦「全能参考」形态)如何组织?时长/分辨率/比例参数面怎么定?旧图生视频表单如何收编?canvas 后端的多参考契约与素材域的音频支持怎么落?

## Answer

1. **入口与锚点(镜像图片模式,ADR 0002)**:工具栏新增「视频」按钮,添加空视频占位节点即从零生成的锚点(今天视频节点只能作为任务产物出现,纯文生视频在「未选中无对话框」范式下无处落脚)。选中视频节点 → 对话框出现、模式自动切「视频生成」且**锁定**(视频产物不能当生图参考,模式下拉的图片生成禁选);选中图片节点 → 默认图片模式,模式下拉可切「视频生成」,切过去时该节点产物自动进参考条、默认角色「首帧」。底栏模式位从占位文本变真下拉(图片生成/视频生成)。发送落点与图片模式同款:空锚点发送直接填入本节点(不新建不连线,任务绑定原节点);有产物或有任务绑定的节点发送落右侧新视频节点并连线、自动选中,参考条随之切换。提示词节点/分析节点不唤起对话框(维持现状)。

2. **参考条:单条 + 角色标记,全模态,不上 tab(方案 A)**。角色集:**首帧(图,≤1)/ 尾帧(图,≤1)/ 参考图(图,≤4)/ 参考视频(≤1)/ 参考音频(≤1)**;chip 按 kind 区分显示(图缩略,视频/音频图标占位,不做波形与抽帧),角色在 chip 上切换,超限整条拒收(`appendComposerRef` 同款纪律)。选中节点产物自动进条:图片节点产物 → 默认「首帧」(12 号票图生视频语义平移),视频节点产物 → 默认「参考视频」。移除参考后发送即文生视频,连线仍建立表达迭代来源(图片模式同语义)。参考组合自然成模式,无显式模式 tab:空 = 文生视频;有首帧 = 图生视频;首帧+尾帧 = 首尾帧;仅参考图 = 多图参考。提示词占位文案随组合变化。**参考条与草稿按模式独立**:视频模式一套 prompt/模型/时长/分辨率/比例/参考条,与图片模式互不清空。

3. **参数面**:模型下拉 = `/video-models` 同源(25 号票落地后目录含 token 轨与 second 轨视频模型,目录端点按「模型须为视频可 served」语义复核是否要放行 token 轨);时长预设 **自动/5s/10s/15s/20s/30s**(「自动」不传 `seconds` 维持厂商缺省;不做自由数字输入,duration 是厂商枚举,自由值多半 4xx;档位取值实现期按 Seedance 实测校准);分辨率预设 **自动/480p/720p/1080p**,选中档位串直接作为 `size` 上送——second 轨计价系数表与 token 轨估算表(25 号票)都以这些字符串为键,契约零新增;比例复用图片模式 `RATIO_PRESETS`(自动/1:1/16:9/9:16/4:3/3:4),走契约新增 `ratio` 参数。提示词必填,发送校验:无提示词不可发;参考结构非法(双首帧等)前端即拦。

4. **收编**:移除图片节点上的图生视频表单——对话框视频模式是其超集(多参考、角色、时长/分辨率/比例),双入口并存会让参考图语义出现两套。图片节点的「分析」入口保留不动;视频节点的反推/分析入口本票不动(遗留清单的「反推/分析同步翻新」另议)。

5. **canvas 后端**:`canvas_tasks` 双方言加列 **`video_refs`**(TEXT/MEDIUMTEXT JSON,元素 `{url,kind,role}`,空 = NULL)与 **`ratio`**(VARCHAR);`size` 复用既有列(视频任务此前不传,现在可带档位串)。`POST /canvases/:id/tasks` 视频任务收 `video_refs` 结构化参考,逐条解引用:`/api/assets/` 路径经素材表解出真实地址并**校验素材 kind 与角色相符**(首帧/尾帧/参考图必须 image、参考视频必须 video、参考音频必须 audio),厂商 http(s) 地址原样透传,data: URI 拒绝(12 号票契约);`image_ref` 单串旧任务照常兼容,worker 对两种形态都认(在途旧任务不受升级影响)。worker 提交网关翻译:`first_frame → image`、`last_frame → last_image`、其余按 kind 进 `references`;`ratio`/`size`/`seconds` 直传。**30s 视频的厂商生成时长是否撞 worker 15min 轮询上限 = 验证点**(超时上限可调,不动默认)。

6. **素材域扩展(音频)**:`/api/assets/upload` 魔数嗅探表加音频(mp3/wav/m4a/ogg/flac,自实现 sniff 与既有同款,客户端声明不受信);素材 `kind=audio`(行、管理面素材页过滤、素材面板列表);预览用 `<audio>` 元素。参考视频复用既有 kind=video 素材,零新增。

7. **验证点**:Seedance 2.5 对各角色参考的实际数量上限(自限 4/1/1 保守,上游超限 4xx 透出即可,节点可见可重试);视频/音频参考在 Ark 侧的 API 形态(25 号票验证点,前端不依赖具体形态);30s 生成 vs 15min 轮询上限。

8. **产出面**:`canvas/web`(GenerationComposer 模式化、编辑器状态与提交路径、graph 数据、ImageNode 表单移除、composer.ts 纯逻辑与单测)、`internal/canvastask`(handler/worker/store 双方言)、`internal/asset`(嗅探 + kind)、`packages/api` 类型;CONTEXT.md「生成对话框」「视频节点」「画布任务」「素材」词条随实现回写。
