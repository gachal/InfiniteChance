# 54 ネーム分镜稿节点

Type: feat
Status: drafted(2026-10-24 grilling 定案;通用画布回归后(53 号票)与絵コンテ同为通用新节点,共享块内核)

## Question

漫画侧的核心工件ネーム(集英社口径「コマ割り + 棒人形 + 台词」,编辑与作家反复拉锯的决定性审查物)。与絵コンテ同为「画面块 + 台词 + 注记」的序列,但媒介心智不同:ネーム以**页**为一级单位(「每页 ネーム」),页内格子有大小节奏(コマ割り),不是线性镜头流;絵コンテ的 cut 有时长/运镜(对应视频生成单位),ネーム的格没有。53 号票定案:类型上分立、内核复用——UI 心智完全不同(镜头流 vs 页面网格),强并一类会让一个节点长两副面孔。

## Answer

- 第八种节点类型 `name`,进工具栏「规划」组,`NODE_TYPE_LABEL` =「ネーム」,全画布可用。
- 节点数据存整图 JSON(后端零改动):`{ title?, pages: Page[] }`;`Page = { title?: string(可空), panels: Panel[] }`;`Panel = { asset_id: number(0 = 空), lines: string(台词/旁白/拟音,多行), size: 'large' | 'small' }`。大小格两档表达节奏,**不做真二维排版**(拖拽定格子框另票)。
- **板卡(预演台帧卡范式,同 53)**:板名(可编辑,缺省「ネーム」)+ 汇总(N 页 · M 格)+ 页首格缩略条;整卡点击进编辑层。
- **编辑层**(复用 53 号编辑层范式与**画面槽组件**;ADR 0002 浮层范式、autosave 链、Esc 双路,全同 53 纪律):页列表(序号 + 页标题 + 上移/下移/删除)→ 页内格子垂直流(序号 + 画面槽 + 台词 textarea + 大/小格切换 + 上移/下移/删除);底部「+ 页」「+ 格」;格可删到空、页可删到空、板可空页(画布工作件,非库实体)。排序按钮不拖拽;序号显示时生成 1..N 不持久。
- **画面槽三入口同 53**:AssetPicker(scope=ip 默认)+ 本机上传(挂画布 IP)+ 落图节点;无专用回填动作,闭环经素材库最近使用排序完成。
- **落图边类型「name → 图片」**(来源语义,storyboard → 图片同族;53 号票已扩 connection 矩阵,本票加一类)。
- 添加即带 **1 页 1 格**;删除节点 = 图 JSON 删节点,素材行不动;「素材不可用」占位契约同 53。
- 与絵コンテ的共享边界:**画面槽交互组件**(AssetPicker/上传/落图/占位)与编辑层骨架复用;数据结构各自定义(`Cut` 与 `Panel` 字段集不同,不强行归一——强归一制造大量空字段)。
