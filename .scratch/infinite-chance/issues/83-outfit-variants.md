# 83 服装变体深化(cut→变体绑定 + 变体成套生成)(2026-11-11 grilling 定案)

Type: feat
Status: 定案(2026-11-11 grill-with-docs 定案,06 号一致性深化裁三项之第一优先;Q7/Q8 全按推荐;待 implement-spec)

## Question

51/52 号票的造型变体(name + note 服装描述)已贯通全链:服装描述进设定图 prompt(70 号票)、元素 chip 按变体选图(71 号票)、cut 出场角色按**默认变体**取图(70 号票 C 节)。机械缺口两处:①cut 只存 `character_ids`,出场角色**恒取默认变体**——换装场次的 cut(如「第三章穿雨衣」)注入的设定图必错装,70 号票 Out of Scope 明文「cut→变体精确绑定另票」;②新变体要出成套视图(三视图/多视图/色板/姿态),现在一次一张手工发 N 次,70 号票 Out of Scope 明文「表情集/姿态等多图的批量编排」另票。本票收编两条。

## 定案(2026-11-11 grilling)

### A. cut→变体精确绑定

1. **数据形状**:`StoryboardCut` 加可空 `character_variants?: Record<number, number>`(角色 id → 变体 id),随絵コンテ节点 data 存整图 JSON——**零迁移**(照 `character_ids` 同哲学:只存引用不存快照,角色/变体改名随目录刷新即变);缺省或映射缺失回落「默认变体」(`defaultCharacterVariant` 既有规则:名为「默认」的变体,改名后回落首个),**存量画布行为逐字节不变**。
2. **编辑入口**:cut 编辑表单的出场角色条目逐角色加变体下拉(选项按本 IP 角色目录实时取;所选变体已删时回落默认变体并显示回落态)。
3. **取图规则**:cut 出场角色取图链(`pickCutCharacterRefs` → `pickVariantAssetId`)改「**cut 绑定变体优先 → 默认变体回落**」;两条消费路径同规则——cut→画面直通(参考条)与 cut→视频无画面注入(元素 chip 带 `variantId`)。
4. **71 号票硬约束不动**:cut→视频**有画面**路径维持「不注入角色设定图」(首帧/全模态参考互斥是渠道硬约束);变体绑定只影响「取哪张参考」,不影响「注不注入」。

### B. 变体成套生成

1. **入口**:资产库抽屉变体节加「成套生成」→ 类型多选对话框,**默认勾视图三类(三视图/多视图/色板)**,表情集/姿态默认不勾(省钱,按需加勾)。
2. **发起**:对话框一次人工确认(含 N 笔任务总价预估)→ **前端循环串行发 N 笔** `POST /api/ips/:id/tasks`(端点零改动,一笔一类型;不新建批量端点)。
3. **独立纪律**:逐笔独立计价、独立失败、部分成功不回滚(某笔 `model_not_priced` 拒绝不影响其余笔);每笔照 70 号票单笔纪律(worker/转存 `ips/` 前缀/前端记账锚定照旧);预填 = **发起时统一**取「变体当前最近一张设定图」作各笔参考图,不串联后续笔(第一笔成功不改变第二笔的参考)。
4. **进度**:抽屉对话框内逐笔进度(列表态,每行一类型一状态)。
5. **70 号票口径修订**:Out of Scope「表情集/姿态等多图的批量编排」条目由本节取代——**同变体逐类型各一笔**的成套生成进本票;「一次请求生成多图」仍不做(一次生成一张不变)。

## 验证点

- 绑定变体:绑定后 cut→画面直通参考条取绑定变体设定图;无绑定/映射缺失/变体已删三种情况均回落默认变体;存量画布(无该字段)直通行为与改动前逐字节一致。
- 成套生成:默认勾三类;N 笔任务逐笔落 `canvas_tasks`(canvas_id=0、ip_id 归属正确);单笔失败不回滚其余笔;刷新丢前端记账后产物在库、抽屉可手动锚。
- cut→视频有画面路径仍不注入(toast 说明文案不变)。
- 纯 canvas/web 改动(节点 data 整图 JSON + 纯函数 + 组件),Go 侧与双方言 schema 零改动;vitest 纯函数测试绿 + build 过 + 浏览器点验。

## Out of Scope

- 配色字段/色指定(84 号票);群像便利层(85 号票)。
- cut→视频有画面路径的注入改造(71 号票硬约束,不做)。
- Agent 聊天注入与 Agent 工具变化(52 号票口径不动;变体绑定是画布节点 data,不进 Agent 域)。
- 「一次请求生成多图」;跨变体批量(成套生成本就按变体粒度)。
