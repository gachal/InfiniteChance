# 30 +号连线交互:节点旁常驻 + 按钮两击连线与轻校验矩阵

Type: grilling
Status: approved（2026-10-01 grilling 定案,待实现）

## Question

画布连线交互太难用:四个节点组件各挂 vue-flow 左右两个 `Handle` 小圆点,连线 = 从 Handle 按住拖到目标 Handle,热区只有小圆点本身,必须精确对准节点边缘才能连。参考即梦的 + 号按钮连线(截图),交互怎么重做?顺手要不要收编连线合法性?

## Answer

1. **点击式两击连线(定案)**:节点**左右各一个常驻 + 按钮**——左 + = 接上游(本节点为 target),右 + = 连下游(本节点为 source)。点击 + 进入连接态:出现跟随鼠标的预连线,合法目标节点高亮、其余置灰;点目标节点完成连线(方向按 + 在左/右自动定);Esc 或点空白取消。全程两击、零拖拽、零精确对准。

2. **移除 Handle 拖拽交互**:旧 Handle 不再响应拖拽连线(Handle 元素仅保留作 vue-flow 边端点锚点,视觉隐藏)。连线交互唯一入口 = + 按钮;程序化连线(反推落节点、composer 发送落新节点并连线、分析动作建节点连线)不受影响,照常直连。

3. **轻校验矩阵(仅前端)**:agent→image/video(投递通道)、video→agent(反推来源)、image/video→analysis(分析来源)、image/video→image/video(迭代来源,21 号票语义);其余组合拒连(连接态里非法目标不可点)。**历史画布已存在的边不动、不清洗**(含 prompt→prompt 等按新矩阵非法的旧边,展示容忍,只是不能再新增);后端整图落库不校验(单管理员,前端矩阵错漏改代码即可,不上锁)。

4. **显式 out of scope**:后端落库校验、批量连线、连线上标签/注记、连线权重或样式分型。

5. **产出面**:`canvas/web`(四个节点组件加 + 按钮、编辑器连线状态机——建议抽 composable 配单测、合法矩阵模块);CONTEXT.md 新增「连线」词条。

6. **验证点**:连接态与框选/多选/拖动节点手势不打架(连接态下点击节点只表达连线意图);历史画布旧边渲染与删除不报错;程序化连线路径回归(反推/composer 发送/分析动作产出的边均落在合法矩阵内,自洽);+ 按钮在节点缩放(画布 zoom)下的命中区域。
