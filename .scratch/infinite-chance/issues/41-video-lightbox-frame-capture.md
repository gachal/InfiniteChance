# 41 视频灯箱截帧:播放中截当前帧落画布

Type: grilling
Status: implemented(2026-10-08 实现;同日 grilling 六问,用户「都按推荐」收口)

## Question

想在「视频预览节点播放时」截取当前帧。实际形态:33 号票起视频节点卡片只显静音首帧缩略,播放集中在媒体灯箱(原生 controls + autoplay)——「播放时截帧」的入口天然在灯箱。截帧的典型动机 = 拿某一帧喂生成链(生图参考/视频首帧),而预演台票(39 号)已定「喂生成链一律经图片节点」,且预演台「渲染帧 → /api/assets/upload 入素材库 → 落图片节点 + 连线」的产物链路可整套复用,后端零改动。

## Answer

1. **入口与范围(Q1)**:灯箱右上角 actions 组第三个按钮(📷,与 ⬇ ✕ 同排),仅媒体为视频时显示;节点卡片不加入口(节点不播放);范围随 33 号票灯箱 = 画布编辑器内的视频节点,素材面板/生成记录面板缩略不接。

2. **产物去向、落位与连线(Q2)**:复用预演台「落画布」全套范式——当前帧经 `/api/assets/upload` 入素材库(kind=image,键落 `uploads/` 档,与用户上传/预演台渲染帧同义)→ 自动落图片节点在源视频节点右侧(x+380,连截纵向级联偏移防叠卡)→ 连线复用既有「媒体→媒体(迭代来源)」边,**不新增第六种边语义**(票面写明:来源语义涵盖帧提取)。本机留档不设单独路径——新图片节点/素材面板都可下载。源节点持有 `asset_id=0` 的厂商绝对地址或 302 回退历史行时截帧必失败(见第 5 点),该场景产物不落。

3. **格式与命名(Q3)**:JPEG 质量 0.92、视频原生分辨率(`videoWidth×videoHeight`,不缩不放);视频帧无透明通道,PNG 的体积(1080p 约 2–4MB)对生图参考无增益。文件名带时间码便于连截辨识:`frame-{当前秒}s.jpg`(一位小数)。

4. **播放行为(Q4)**:点击/S 键截帧**不暂停**、可无限连截(播放中连截不同帧是主场景);每帧独立上传独立成节点;截完轻反馈(toast)。连拍/区间抽帧 out of scope 另票。

5. **跨源兜底(Q5)**:常态(素材行有自有字节)dev 代理/部署 nginx/桌面 webmux 全部同源,`drawImage` 不污染;历史行 302 回退厂商 CDN、`asset_id=0` 旧任务直连厂商地址时 canvas 被污染,`toBlob` 抛 SecurityError——捕获后 toast 显式报「该视频来自外部临时地址,无法截帧」,不静默。不给 video 加 `crossOrigin`(302 无 CORS 头时反而可能连播放都坏)。

6. **键盘快捷键(Q6)**:灯箱打开且媒体为视频时按 `S` 截帧(带 Ctrl/Meta/Alt 修饰键不触发,不劫持 ⌘S);Esc 关闭语义不变。

## 显式 out of scope

连拍/区间抽帧/批量导出;图片节点任何改动(图片直接下载即可);素材面板、生成记录面板、Agent 历史面板的媒体缩略接灯箱/截帧(33 号票范围决策继续有效);节点卡片入口;后端任何改动(上传走既有端点,零 schema 变更)。

## 产出面

- `canvas/web`:`MediaLightbox.vue`(video ref + 📷 按钮 + S 键 + `drawImage → toBlob('image/jpeg', 0.92)`,失败上抛 `capture-error`);`CanvasEditorView.vue`(lightbox 态带源节点 id、`onLightboxCapture` 入素材+落节点+连线、toast 层级 20→120 使反馈浮在灯箱 z-100 之上)。
- `packages/api`:零改动。**后端零改动**。

## 验证点

灯箱视频播放中点 📷 / 按 S 出帧落画布、连截多帧各自成节点且级联偏移、新节点带 uploads/ 档素材引用可喂生成对话框;截帧不暂停播放;图片灯箱无截帧按钮、S 无效;Esc/×/遮罩关闭不受 S 键影响;toast 反馈在灯箱之上可见;上传失败 toast 报错;`make test` + `make lint` + 前端构建。外部地址历史行的 SecurityError 路径本机无样本,按代码路径审查 + 真机遇到再验。
