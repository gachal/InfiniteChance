# 52 角色消费面:角色引用节点与设定文本注入

Type: feat
Status: drafted(2026-10-24 grilling 定案;**依赖 51 号票存储面**[characters/variants/images 三表与目录 API];上游:50 号票节点类型注册机制)

## Question

51 号票落了角色存储面(IP 级实体 + 造型变体 + 设定图锚),画布侧尚无消费入口:画布上看不到角色,Agent 拿不到角色设定。业界两条消费路——图像锚(51 已落,经生成对话框参考条)与文本注入(Sudowrite Story Bible 式,圣经条目进上下文)。本票把两条路都接进画布。

grilling 定案要点:角色引用节点是**通用节点**(全画布类型可用——角色跨媒介是本质属性);data 只存 id 不存快照(one source of truth 彻底贯彻);节点不参与连线;文本注入走**显式引用**不做自动检测。

## Answer

**角色引用节点(第六种节点类型 `character`)**:

- `graph.ts` 类型清单加 `character`(含 normalize 白名单、`NODE_TYPE_LABEL`「角色」);**适用画布类型 = 全部**,工具栏添加按钮组收入;`CanvasEditorView` 插槽注册 `CharacterNode.vue`。
- `CharacterNodeData { character_id: number }`——**只存 id 不存快照**:角色改名/换封面/加变体,旧节点跟着变;快照方案否决(违背 51 号票的 one source of truth)。
- 渲染:编辑器按画布 ip_id 拉本 IP 角色目录(51 的 `GET /api/ips/:id/characters` 完整树),节点按 character_id 订阅;角色不存在(已删)或跨 IP 显示「角色不可用」占位,可删节点或换绑(节点检查器选其他角色)。
- 卡片内容:封面首图(首个变体排序最前的视图类图,thumb 302)+ name/alias + **变体 tabs**(按变体切换显示该变体设定图缩略,视图类置前)+ 逐图「落图节点」动作。
- **落图节点 = 素材插入语义**:把选中设定图插为独立图片节点落当前视口中心(asset_id + 内容寻址,不复制字节,**不连线**——角色节点不在连线矩阵中);这是设定图进生成链的桥(落图后经对话框参考条/首帧消费)。
- **连线矩阵零改动**:`character` 不作任何连线的源与目标(不渲染 + 把手)——它是钉在画布上的设定参照卡;「本镜头主角」类连线语义显式不做,等真实工作流逼出来另票。

**设定文本注入(Agent 节点)**:

- Agent 输入区技能 chip 旁新增**角色 chip**:显式入口唤起本 IP 角色选择列表,选中成可删 chip、可多枚(按选择序);**不做消息自动检测激活**(NovelAI 激活键语义复杂且不可预期,单管理员不需要)。
- 服务端 promptgen:`POST /canvases/:id/generate-prompt` 与 `/stream` 流式变体请求体加可选 `character_ids[]`——校验角色存在(`character_not_found`)+ `character.ip_id == canvas.ip_id`(`character_ip_mismatch`),通过后把每个角色渲染为「【角色设定】\n名字:…\n别名:…\n简介:…\n设定:\n<detail>」段,**拼在技能渲染文本之后、用户输入之前**(messages 首条 = 技能文本 + 角色设定段);错误形状画布面统一 `{"error":{code,message}}`,流式变体沿用「没过完校验不给流」纪律。
- **注入只带角色级字段**(name/alias/description/detail);变体名与服装描述不注入(视觉一致性走 51 图像锚)。
- token 成本记 Agent 调用自身账,用量日志无新形状。
- **历史固化**:已发送轮次里的设定文本随 messages 持久在节点 data——角色后改不影响已发生对话(历史事实);新轮次/新会话取最新角色数据。换技能 = 开新会话(既有语义)连带清角色 chip;「新会话」按钮同理。
- **媒体节点不加角色引用**——媒体一致性走图像锚,文本注入只服务 Agent 的提示词生产。

## 产出面

- `canvas/web`:CharacterNode.vue(组件 + 插槽 + 工具栏)、Agent 输入区角色 chip 与选择列表、编辑器角色目录取数(canvas.ip_id 维度)。
- `internal/promptgen`:请求体扩展 + 双校验 + 设定段拼接(同步与流式两端点同形);canvastask 零改动。
- 测试:注入拼接形状(位置/多角色/字段)、限本 IP、角色已删、流式校验前置;前端节点渲染/实时性(改名后节点变)/占位/落图/chip 流/会话清空语义。

## 部署侧动作(代码外)

无。

## 验证点

- 添加角色节点 → 选本 IP 角色 → 渲染封面与变体画廊;角色改名/加变体后节点刷新即变(不存快照的实证)。
- 删角色 → 节点「角色不可用」占位;换绑另一角色恢复。
- 落图节点:任意变体的设定图一键落独立图片节点、视口中心、无连线、可进对话框参考条。
- 注入:带角色 chip 生成提示词,messages 首条 = 技能文本 + 【角色设定】段 + 用户输入序正确;多角色按选择序;跨 IP 角色 400 `character_ip_mismatch`;已删角色 404;流式变体校验失败仍是 JSON 错误不开流。
- 换技能/新会话清角色 chip;发送后历史轮文本固化(角色后改旧对话不变)。
- `make test` + `make lint` + 浏览器点验。

## Out of Scope

- 变体级注入(变体名/服装描述进上下文)、角色节点连线语义、节点内直接编辑角色、跨 IP 引用、注入 token 单独计量、自动检测激活。
