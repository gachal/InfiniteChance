# 53 通用画布回归与絵コンテ分镜节点

Type: feat
Status: implemented(2026-10-24;feat/universal-canvas,A/B 两段与评审修复均已并入)。定案背景:同日 grilling 推翻 50 号票「画布类型 + 特色节点」结构,见 [ADR 0005](../../../docs/adr/0005-universal-canvas-and-node-grouping.md)

## Question

50 号票引入「画布类型 + 特色节点」双轨:canvases.type 四类媒介标签,特色节点按画布类型过滤挂靠。但机制落位即空载——适用性注册表全部 `'all'`,类型对节点行为零影响。53-55 三类规划工件(絵コンテ/ネーム/关卡)切票时重新审视,发现它们是数据结构自身完整的工作件,不依赖画布媒介语义;单用户创作早期媒介混沌,一张画布混用预演台 + 分镜 + 关卡是真实工作流,「画布作为自由空间承载非表单工件」与「这张画布只许摆某类节点」互相拧巴(方法论见 [研究纪要](../research/ip-methodology.md);推翻论证见 ADR 0005)。

同票解决两件事:**A 段**把画布回归通用(50 号票部分结构退役);**B 段**落第一个规划节点——动画絵コンテ(吉卜力口径「分镜 = 剧本 + layout + 美术指导三合一」:每 cut 画面、时长、台词、运镜、效果注记)。

## Answer

**A 段:通用化改造(50 号票部分结构退役)**:

- 画布回归通用:`NODE_TYPE_APPLICABILITY` / `nodeTypesForCanvasType` 删除,添加面板全节点可见;`canvasTypes.ts` 注册表整体退役删除,新建 POST 不带 type(后端缺省 `general`)。
- `canvases.type` 列与后端接口**冻结保留**(双方言不删列):存量值不动,PATCH type 接口保留但前端无入口,前端不再读写展示 type——存量 `animation` 等值成为不可见的库内历史事实,后端零改动。
- 新建画布对话框撤类型卡 = 仅名称输入(IP 详情页入口);IP 详情页画布区**平铺**(按 updated_at 新到旧),撤类型分组;行内操作(打开/重命名/移动/删除)与素材区(scope=ip)不变。
- 编辑器面包屑撤类型徽章(「IP 名 / 画布名」保留)。
- 工具栏添加按钮分两组:「**创作**」(图片/视频/Agent/预演台/角色;analysis 仍仅由动作创建)+「**规划**」(絵コンテ/ネーム/关卡),组间分隔线;54/55 落地前规划组先只有絵コンテ一项。
- 文档回写:ADR 0005(已随定案落笔)、ADR 0004 顶部取代注记(已落笔)、CONTEXT.md「画布类型」词条重写 + 「IP 企划」词条更新 + 新增「规划节点」词条、本票与本注记、README 创作画布段微调(随实现改,定案不先行改文案,50 号票先例)。

**B 段:絵コンテ节点(第七种节点类型 `storyboard`)**:

- 节点数据存**整图 JSON**(预演台先例,后端零改动):`{ title?, cuts: Cut[] }`;`Cut = { asset_id: number(0 = 空画面), seconds?: number, lines: string(台词/音效,多行), camera_moves: string[](运镜白名单多选), note?: string(一行备注) }`。运镜白名单前端持有(初始集:推/拉/摇/移/跟/固定/手持/变焦),后端存串不校验(51 号 label 同哲学)。
- **板卡(预演台帧卡范式)**:节点卡 = 板名(可编辑,缺省「絵コンテ」)+ 汇总(N cut · 合计 M:SS,时长非空求和)+ cut 画面缩略横条;整卡点击进编辑层,卡上动作按钮除外。
- **编辑层**(编辑器级全屏浮层,ADR 0002 范式,Teleport 单实例,灯箱/预演台编辑层同族;场景改动走 scene-change → updateNodeData → autosave 链,40 号票纪律;Esc/返回按钮双路等价):垂直 cut 列表,每 cut = 序号(显示时生成 1..N,不持久,删插自动重排)+ 画面槽 + 时长输入(失焦夹紧)+ 台词/音效 textarea + 运镜 chip 组 + 备注行 + 上移/下移/删除;底部「+ cut」。cut 可删到空(板是画布工作件,非库实体——与角色变体「最后不可删」相反)。排序用按钮,**不做拖拽**(40 号票编辑层手势冲突教训)。
- **画面槽(双向素材闭环)**:三入口——素材库选(AssetPicker,复用 47 号组件,scope=ip 默认)+ 本机上传(经 `/api/assets/upload`,挂画布 IP)+ 落图节点。**无专用「设为分镜画面」动作**:生成产物即素材行,AssetPicker 按最近使用排序(47 号票)就近可得——「草图 → 生成 → 回填」闭环经素材库完成,零新交互。
- **落图节点**:cut 有画面时可落——右侧新图片节点(asset 引用 + 内容寻址,prompt 空)并连线,新增边类型「storyboard → 图片」(来源语义,预演台 → 图片同族;connection 轻校验矩阵前端拒绝其余组合,后端不校验);无画面 cut 落图禁用。
- 添加即带 **1 个空 cut**(预演台「添加即可见」先例);删除节点 = 图 JSON 删节点,素材行不动;引用素材被删画面槽显示「素材不可用」占位(既有契约)。
- 新节点进「规划」组,`NODE_TYPE_LABEL` =「絵コンテ」;与 54 号ネーム的共享边界 = **画面槽交互组件**(AssetPicker/上传/落图/占位)与编辑层骨架复用,数据结构各自定义(cut 与 panel 字段集不同,不强行归一)。
