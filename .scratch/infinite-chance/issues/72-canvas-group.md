# 72 画布分组(canvas group)(2026-11-02 grilling 定案)

Type: feat
Status: defined(2026-11-02 grill-with-docs 定案,Q1–Q14 两轮全按推荐;尚未实现。纯前端 canvas/web,网关、canvas/server、packages/api、任何表零改动)

## Question

画布需要分组:画一个区域,进入的节点都属于该分组,移动分组时节点一起移动;参考成熟平台最佳实践。

现状:画布 12 种节点自由摆放,图内无任何组织手段(唯一「分组」是 ADR 0005 工具栏按钮的创作/规划分类);图 = 单 JSON 整图(`canvases.graph`),后端不解释形状,`PUT /canvases/:id/graph` 整图乐观锁 + 整图快照撤销栈;vue-flow 1.48.2 零 subflow 用法,框选(Shift 拖)与多选拖动开箱即用,但无框选后批量操作 UI。

调研(已查证):归属两种模型——ComfyUI 画框是**几何包含**(节点中心点在框内即成员,每次移动实时重算不入库,误捕获邻居、节点不能摆框外边缘);React Flow/vue-flow `parentNode`、Figma Frame、tldraw、Weavy(AI 画布唯一有原生分组者,2026-01)、n8n 2.28 Canvas Groups 是**显式引用**(成员列表入库)。vue-flow `parentNode` 的坑:子坐标变相对父坐标(渗入落点算法/任务回写/整图 JSON 的所有 position 语义)、默认删父留悬空引用(`NODE_MISSING_PARENT`)、默认子可拖出父外仍保持归属。共识:组框永远在节点之下;折叠都是分组之后的独立能力;嵌套无一家做好。Dify/Coze/即梦/可灵/Krea/Flora/Recraft 均无画布分组。

## 定案(2026-11-02 grilling)

### A. 概念与数据模型(Q1 / Q2 / Q3)

1. **术语「画布分组」(canvas group)**:CONTEXT.md 新词条,与 ADR 0005 工具栏「节点分组」(创作/规划按钮组,纯展示)显式区分。
2. **第 13 种节点类型** `type: 'group'`(组织装饰节点,非内容节点):data = `{ title, color, memberIds: string[], w?, h? }`;**所有坐标绝对**(节点 position 语义零变化);`graph.ts` 类型注册表显式登记 `group`(`CanvasNodeType` / `initialData` / `isCanvasNodeType`),防 `normalizeNodeType` 把未知类型吞成 agent。
3. **成员关系单源存组侧**:成员节点 data 零改动(12 种既有类型完全不动);节点删除时组侧清理悬空 id;组删除只删组节点。`canvas_tasks.node_id` 永不指向组(组不是任务节点,worker 回写零冲突)。
4. **归属模型 = 显式成员 + 自动进出**(Figma/Weavy 语义;否决 ComfyUI 几何中心重算——AI 画布节点是大图/视频卡,中心点几何判定误捕获风险高):拖入框内释放 = 加入、包围盒中心出框 = 脱离、跨组拖动 = 换组;**框是视觉不是归属判据**,成员列表才是事实。
5. 后端零改动:组随整图 JSON 走;成组/解组/拖组走既有 `markChanged()` 链路,整图快照撤销天然原子;存量画布无 group 节点天然兼容;4 MiB graph 上限余量充足(组 data 只有标题/色/成员 id/尺寸)。

### B. 创建与成组(Q5 / Q11 / Q14)

1. **入口一:框选成组**——框选若干节点 → `Ctrl/Cmd+G`,框自动包住所有所选节点;跨组成员一律换组(脱离原组入新组,显式成员下就是一次成员列表改写);组节点不进框选结果(见 E1),不会被误并入。
2. **入口二:工具栏画空组**——工具栏新增「组织」组(照 ADR 0005 纯展示分组机制扩第三组),内含「分组」按钮;点击进入画框模式(按钮激活态):劫持 pane 拖动画出矩形、单次生效(画完即退出激活态)、Esc 或再点按钮取消;画出的矩形 = 空组的用户设定尺寸。
3. 缺省值:标题「分组」、颜色 = 色板第一色;无拖画的编程创建落最小占位 260×160。

### C. 归属判定与拖动(Q6 / Q12 / Q2)

1. **判定锚点恒为节点包围盒中心**,三处同一锚点:拖入加入、拖出脱离、落点自动入组。中心出框即脱离,无滞回阈值(高亮反馈已消除歧义)。
2. **实时高亮**:拖动中节点中心悬在哪个组框,该框高亮描边(「松手将加入」);释放落定。拖动中框不实时扩,释放后一次性 expand(避免视觉抖动)。
3. **多选拖动**:释放时逐节点按中心各自判定归属(可部分入组、部分换组、部分脱组)。
4. **落点自动入组**:直通生成落新节点、Agent 产物落点、素材面板插入、工具栏添加(视口中心落点)等——落点中心在组框内即自动成为成员;这是把一组生成链圈进分组后,迭代产物自动留组的关键体验。任务产物回写(位置不变)天然不涉及。
5. **拖组移动**:点组框空白处或标题栏拖动 = 整组移动(组节点位移 + 成员同 delta 同步);拖成员只动该成员(框随之自动扩/缩)。

### D. 框尺寸(Q4 修正为 Q9 的混合模型)

1. **框实际尺寸 = max(用户设定尺寸, 成员包围盒 + 内边距 24px)**;用户设定尺寸存组 data(`w`/`h`,与 title/color 同层)随既有 `snapshot()` 入库——这是「装饰尺寸不入库」惯例的**显式例外**:组框尺寸是必要状态,不是运行时装饰。
2. auto-expand:成员入组撑破时扩张;成员移出/删除后回落到 max(剩余成员包围盒 + padding, 用户设定尺寸)。
3. 成员清空回落用户画的大小;**空组保留**(可继续往里拖节点),不被自动清除。
4. **四角 resize 手柄进 MVP**:更新用户设定尺寸,不影响成员位置;「适配成员」(Resize to Fit)按钮不做(auto-expand 已覆盖)。

### E. 选中与操作 UI(Q10 / Q7 / Q14 / Q13 / Q8)

1. **组不参与框选**(vue-flow 框选按矩形相交命中,组框巨大几乎必被扫中——框选结果恒过滤组节点)、**不参与多选**(Shift 点选、跨组多选均不含组),**点选单选**(点框空白/标题栏);选中组时生成对话框不唤起(组非 image/video,天然不满足);组不可作两击连线端点(不渲染把手)。
2. **删组 = 解组,成员原地保留**(Figma/Weavy 共识;节点是创作资产,误删代价高);入口 = 选中组按 Backspace / 标题栏「解组」钮——删除与解组同义,只留「解组」一个语义。
3. **标题栏常驻**组框左上(缺省「分组」,双击内联改名,单击留给拖动/选中);**选中时**标题栏右侧浮出操作钮:**色板**(6-8 预设半透明色)+ **解组**。
4. 快捷键:`Ctrl/Cmd+G` 成组、`Ctrl/Cmd+Shift+G` 解组(选中组时);68 号票帮助浮层(`canvasHelp.ts`)补「画布分组」条目。
5. **组不吸纳组**(memberIds 只收普通节点,拖组 A 入组 B 无效果);**不嵌套**(一层即止);**组与组可视觉重叠**(显式成员下归属与视觉解耦,后画的框在上)。
6. 分组是**纯组织语义**:不影响生成链、计费、任务、连线矩阵、composer 锚点(组不可作 composer 锚点)。

### F. 渲染层级与技术定案(不问、直接落票)

1. 组节点 z 固定压底,**禁用 `elevateNodesOnSelect` 对组生效**(否则选中组会盖住成员);边呈现在组框之上、成员照旧(实现时验证 vue-flow 层序,必要时显式设边 zIndex);minimap 隐藏组节点(大色块喧宾夺主)。
2. 组框视觉:半透明填充 + 描边 + 标题栏,色板与选中态同源(具体样式实现定)。
3. 建议新纯函数模块 `canvas/web/src/canvasGroup.ts`:归属判定(中心点入框/出框)、成组合并(跨组换组、组节点排除)、解组、框尺寸合并(max/expansion/回落)、落点入组判定——全部可 vitest。

## 边界

- **改动面**:只动 canvas/web——`graph.ts`(类型注册)、`canvasGroup.ts`(新纯函数)、`CanvasEditorView.vue`(拖组位移、框选过滤、落点入组、画框模式、快捷键、minimap 过滤)、`CanvasToolbar.vue`(组织组 + 分组按钮)、`canvasHelp.ts`(帮助条目);12 种节点卡组件与 `NodePorts.vue` 零改动;网关、canvas/server、`packages/api`(`CanvasGraph` 为 `unknown[]` 不解释图)、任何表零改动。
- **ADR**:不需要——无难以逆转的架构取舍(组节点方案 vs `parentNode` 已在票内记录理由;单 JSON 整图使本功能天然可逆)。

## 验证点

- **纯函数单测**(vitest):
  - 归属判定:中心点入框/出框/边界,多节点批量判定互相独立;
  - 成组:跨组换组(旧组 memberIds 移除、新组加入)、选区含组节点被排除、对已同组成员幂等;
  - 解组:组节点移除、memberIds 清理、成员 data 不变;
  - 框尺寸:max 合并、expand(入组撑破)、回落(移出/删除回落剩余包围盒、清空回落用户尺寸)、resize 只改用户尺寸;
  - 落点入组:中心在框内/外、组节点永不被吸纳、空组接受;
  - `normalizeNodeType('group')` 保留、未知类型仍回落 agent(回归)。
- **构建与点验**:`make test` / `make lint` / `make build` 全绿;浏览器点验——框选 Ctrl+G 成组、工具栏画框(含 Esc 取消)、拖入/拖出/换组实时高亮、拖组整组移动、双击改名、色板换色、解组后成员原地保留、删成员框收缩、空组保留、落点自动入组(直通生成/素材插入)、组不参与框选、minimap 无组、成组后 ⌘Z 一步回滚、选中组不唤起 composer。

## Out of Scope

- **折叠收组**(组收成标题块):另票——折叠要处理边重定向与展开推挤,且 n8n/ComfyUI 都是分组先上、折叠独立做。
- **嵌套组**:不做,一层即止。
- **「适配成员」按钮**(Resize to Fit):auto-expand 已覆盖。
- **右键菜单入口**:项目画布无右键菜单惯例。
- **组的生成链语义**(按分组批量生成等):分组纯组织,不影响计费/任务/连线;要扩展另票 grilling。
- **成员侧反向字段**(groupId 存成员侧):否决——单源存组侧,成员零侵入。
