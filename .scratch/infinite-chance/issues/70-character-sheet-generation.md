# 70 角色设定图生成与出场角色联动(角色库出图 + cut 角色注入)(2026-11-01 grilling 定案)

Type: feat
Status: implemented(2026-11-01 定案,已实现(2026-11-01,feat/70-character-sheets);依赖的 69 号票 IP 风格字段已先行落地)

## Question

角色库(51/52)落地后角色只有文字四件套 + 造型变体 + 设定图素材引用,**没有生成入口**——「角色的主要资产是三视图/多视图设定画」是术语表明文口径,但三视图目前只能外部生成后手动上传;设定文本进生图 prompt 无自动通道。同时 cut 的 `character_ids`(67 号票)标注了出场角色但「出场角色→生成注入」显式 Out of Scope 留作二期。需要定案:角色设定图(三视图优先)怎么生成、入口放哪、产物怎么锚回角色库、cut 出场角色怎么注入。

## 定案(2026-11-01 grilling)

### A. 无画布任务路径(基建,Q6=A;[ADR 0007](../../../docs/adr/0007-canvas-free-generation-tasks.md))

1. **canvas_tasks 放开无画布任务**:双方言加列 `ip_id`(0 = 画布任务;存量行不回填——画布任务归属照旧查画布,本列仅 `canvas_id=0` 任务消费);任务行允许 `canvas_id=0`(既有 `POST /canvases/:id/tasks` 路径校验不变,新端点不绑画布、`node_id` 为空)。
2. **新端点**(canvas/server JWT 会话面,同 characters):`POST /api/ips/:id/tasks`(kind 仅 image,payload 同画布 image 任务:prompt/model/size/background/image_urls)+ `GET /api/ips/:id/tasks`(列表)+ `GET /api/ips/:id/tasks/:tid`(单查轮询);校验 IP 存在;未配 `CANVAS_SERVICE_KEY` 同码 `gateway_unconfigured` 拒绝。端点形状不排他——场景/道具将来复用另票。
3. **worker 归属与对象键**:素材行 `ip_id` 读取 = 任务行 `ip_id` 优先(canvas_id=0 时)、画布任务照旧查画布;转存对象键任务无画布时落**新前缀 `ips/{ipID}/{taskID}/{kind}.{ext}`**——硬性约束 7 三分归档增补为**四分**(canvases 任务产物 / uploads 用户上传 / relay 直连转存 / ips 库级生成产物),48 号票跨前缀复用与按 object_key 计数删除防护语义不变。
4. **来源标记**:`X-InfiniteChance-Source` 形如 `ip=<id> task=<ct> gen=asset`;admin 用量审计 source 过滤加 `asset` 档(后端 WHERE + admin-web 下拉)。
5. **可见性**:生成记录面板按画布查、天然不见这些任务——进度看抽屉对话框状态,admin 素材页兜底产物枚举。

### B. 设定图生成(五类型 / 两入口 / 自动锚)

1. **五类型**(label 白名单六类去「其他」):**三视图(默认)/ 多视图 / 表情集 / 色板 / 姿态**;类型→prompt 模板为 canvas/server 代码常量(照分析指令先例,不进技能库;三视图 = 全身站姿正/侧/背三视图对照白底设定图);prompt 总长截断 ≤2000 runes。
2. **prompt 拼装** = 类型模板 + 角色四件套(name/alias/description/detail)+ 变体名/服装描述(note)+ IP 风格段(69 号票,若有)。**域口径分叉声明**:生图注入变体服装描述是新增口径——52 号票「变体不注入」仅限聊天文本注入,不变。
3. **参考图默认**:变体下已存设定图时默认带**最近一张**进参考条(`image_urls`),预填可手动移除(一致性红利与干净重 roll 兼得,Q8=A)。
4. **入口一(画布侧)**:CharacterNode「生成设定图」动作 → 落空图片节点 + **新边型「角色→图片」**(设定图来源语义,67 号票直通生成范式)+ composer 预填(类型选择器默认三视图、变体 = 卡片当前选中变体、参考条按上条预填)+ **人工确认发送** → 任务成功前端回调锚定(`POST /characters/:cid/images`:asset_id + variant_id + label = 所选类型)。
5. **入口二(抽屉侧)**:AssetDrawer 角色详情加「生成设定图」→ 抽屉内**轻量生成对话框**(选变体 + 类型;模型/尺寸/价格预估/参考条复用 composer 逻辑,不搬 composer 组件——composer 是画布锚定单实例)→ 走无画布任务 → 对话框内轮询进度 → 成功自动锚。
6. **回填 = 前端内存记账**(task→角色/变体/label,照 cut 直通生成 `cutFramePending` 先例);刷新丢映射时产物仍是素材(抽屉/素材库可见),可从抽屉手动锚兜底;同 label 多张并存,重 roll 不覆盖旧图(character_images 既有语义)。
7. **52 号票口径修订**:角色引用卡「不作任何连线端点」→「**仅可作设定图来源边的源**」(预演台只作源同族);前端连线轻校验矩阵加「角色→图片」;历史已存边不清洗不校验。

### C. cut 出场角色注入(Q9=B 纳入本票)

1. **两条直通路径都注入(Q12=A)**:cut 画面直通生成 + cut→视频直通,预填时按 `cut.character_ids` 逐角色取「**默认变体**」设定图作参考图:优先该变体最新一张视图类(label ∈ 视图五类)> 任意设定图 > 封面投影;角色无任何图**静默跳过**(cut 画面描述兜底,不报错不阻塞,Q11=A);cut→变体精确绑定另票。
2. **上限守卫**:与既有参考合计超 9 按序截断 + toast「N 个角色设定图未带上」(44 号票显式拒收精神的预填形态);视频路径注入角色 = `reference_image`。
3. cut→视频预填 prompt 拼装照 67 号票(画面/台词/运镜/景别)+ 风格段(69),角色设定图只进参考条不进 prompt。

### D. 边界

- 场景/道具的设定图生成不做(65 号票实体,端点形状已预留);cut→变体绑定另票;Agent 聊天注入规则不动(变体服装仍不进聊天)。
- **花钱操作永不进工具循环**:设定图生成走 composer / 抽屉对话框人工确认,不进 Agent 领域工具(63 号票纪律)。
- 锚定写库表不落边(52 号票素材插入语义);「角色→图片」边只表达生成来源,不承担回填。

## 验证点

- 无画布任务全链:create → worker 认领 → 网关生图 → 转存 `ips/` 前缀 → 素材行 ip_id 正确 → GET 轮询终态;失败退款/原地重试/重启恢复照画布任务纪律;双方言集成测试绿(含 ip_id 加列迁移)。
- 前端锚定:两入口各生成一张,character_images 新行 variant/label 正确,抽屉画廊即时可见;刷新丢映射时不自动锚、素材在库可手动锚。
- 五类型逐类对账:prompt 含模板+四件套+变体服装+风格段(有则),label 落库正确。
- cut 注入:多角色 cut 预填参考条序 = character_ids 序;>9 截断 toast 计数正确;无图角色跳过;cut→视频路径 reference_image 角色正确。
- 连线矩阵:角色→图片可连,角色→其余目标置灰,角色仍不可作任何边的目标;落图产物与角色卡的边在图上可见可删。
- 审计:usage_logs 的 source 带 `ip=… gen=asset`,admin 审计 asset 档过滤命中。

## Out of Scope

- 场景/道具设定图生成(另票);cut→变体精确绑定(另票);批量逐 cut 生图/生视频(68 号票边界注记的三期)。
- 设定图生成进 Agent 工具循环;无画布任务的全局任务列表 UI(抽屉对话框状态 + admin 素材页已覆盖)。
- 表情集/姿态等多图的批量编排(一次生成一张,多次生成并存);设定图的云端二次处理。
