# 73 分镜提示词对齐 Seedance 2.0(storyboard prompt alignment)(2026-11-02 grilling 定案)

Type: feat
Status: grilled(2026-11-02 grill-with-docs 定案,两轮 Q1–Q13;待实现)。**口径注记**:①cut 字段零扩(参考图元素全靠写作纪律装进 note/lines,拼装照旧整段透传);②小节秒数参照照进 prompt 文本——用户拍板推翻官方「精确时间不稳不建议写」的告诫,以参考图实测打法为准;③「默认基调 = IP 风格」走纪律承接落法(双段并存,brief 视觉基调小节以 ips.style 为基底下笔),不动 69/70 号票已实现的段语义。

## Question

剧本导演产出的分镜提示词太瘦:导演系统提示词对「一镜该写什么」只有一句工具守则,没有画面写作规范;全片级基调/空间坐标/音效总纲没有家,每镜重复或缺失;cut→视频拼装模板未对齐 Seedance 2.0 官方提示词指南(公式、符号规范、约束词),且「【画面风格】」段误用官方字幕标记 `【】`、绑定行「图N」与官方「图片N」指代有偏差。

对标物:用户提供的成熟分镜提示词设计(30 秒真人东方神话高空双线缠斗,关键词条/视觉基调/主要角色与设定/场景与空间坐标/时间段×{镜头与画面设计/动作与台词/视觉与特效要点}/音效设计三层)。

## 调研(已查证)

- **链 A(剧本导演产出分镜)**:`internal/promptgen/agentdirector.go` 系统提示词 + `internal/agenttools/drafts.go` `storyboardCutSchema`。cut 字段:note(画面描述/备注)/ shot(景别单选)/ camera_moves(运镜多选)/ lines(台词音效多行)/ seconds / character_ids / asset_id;画面不填由用户后续配置(66 号票)。
- **链 B(cut→视频/图片拼装)**:`canvas/web/src/storyboard.ts` `buildCutVideoPrompt`(【画面风格】→画面描述→景别→运镜→台词/音效,空段跳过)/ `buildCutFramePrompt`(画面描述+景别);发送时叠 71 号票绑定行「出场元素:名字@图N(角色)」(`element.ts`,`REF_INDEX_LABEL='图'` 单点常量,注释明写「真 key 有差异时只改这里」);风格段 `canvas.StyleSegment` ↔ `ipStyle.ts` 双侧同形、字面量测试互钉。
- **Seedance 2.0 官方指南**(ark.volcengine.com):进阶公式「精准主体+动作细节+场景环境+光影色调+镜头运镜+视觉风格+画质+约束条件」;每镜四要素「运镜→主体动作表情→位置/空间变化→音频」;动作肢体细化+程度量化、情绪外化身体细节;一镜一种运镜;符号规范台词`{}`/音效`<>`/音乐`()`/**字幕`【】`**;约束词「保持无字幕/不要生成Logo/不要生成水印」;素材推荐 4–5 个。
- **两处现有定案与指南冲突**:①「【画面风格】」段(69 号票)用了官方字幕标记 `【】`,可能把「画面风格」渲染成字幕(71 号票 E 节已列真 key 验证点);②`camera_moves` 多选顿号连接 vs 官方一镜一运镜。
- 研究纪要候选池 2「分镜提示词按目标模型格式重写」仍未做;71 号票 E 节边界「不按模型特判」为现有定案。

## 定案(2026-11-02 grilling)

### A. 范围与术语(Q1 两轮)

1. **两条链都动,链 A 为主**:链 A 重写导演系统提示词+schema description(把参考图的分镜写作规范注入);链 B 调拼装模板与发送拼装。只改一边都是无米之炊或无人管束。
2. **保持渠道无关**:四要素顺序、动作量化、符号规范、约束词对 MiniMax/百炼等中文 prompt 渠道无害甚至有益;不做按渠道分支,ark/minimax/dashscope adaptor 翻译层零改动(71 号票边界不动)。

### B. 全片基调 brief(Q3/Q2 两轮,Q8)

1. `StoryboardNodeData` 加可选 `brief`(多行文本,中文标签「全片基调」);旧分镜板无此字段拼装自动跳过,零迁移;brief 随整图 JSON 走(53 号票先例,后端零改动)。
2. 内容三段(导演纪律约束写法,不拆子字段):①视觉基调(场景氛围/色彩光源/画面强调)②场景与空间坐标(地点/布局/各主体站位/机位相对动作的方位/同框纪律)③音效总纲(底层/中层/顶层分层)。
3. 落点:`save_storyboard` 加可选 `brief` 参数(落板时一并产出);絵コンテ编辑层顶部多行文本域可手改。
4. 拼装位置:画面风格段之后、画面描述之前,标签「全片基调:」;brief 非空恒拼,**不受 composer「带 IP 风格」开关管**——开关只管 `ips.style` 段,brief 是 cut 板数据本身。
5. **默认基调 = IP 风格(Q8=A 双段承接)**:导演纪律——brief 的视觉基调小节以 `ips.style` 为基底下笔、再叠本集增量;未定风格先走既有 `set_style` 提议流程;brief 空 = 风格段独自承担基调;永不出现两段同文。

### C. 分镜写作纪律(Q2/Q5/Q7 第一轮;Q4/Q5 第二轮)

1. 导演系统提示词加「分镜画面写作纪律(强制,每镜执行)」段,`storyboardCutSchema` 各字段 description 改为指向纪律:
   - note 按「运镜→主体动作与表情→位置/空间变化→画面要点」顺序写;动作肢体细化+程度量化(具体到手/腿/头部,带幅度速度力度),情绪外化为身体细节(低头、肩膀颤抖、眼眶泛红),禁用「很有电影感」类空洞词。
   - 一镜跨节拍按小节写:「镜头1(00:00-00:02):…」「镜头2(00:02-00:04):…」;**小节+秒数参照照进 prompt 文本**(用户拍板,官方「精确时间不稳」告诫以实测为准);秒数连续、小节合计=本镜 seconds;一镜最多 3 小节,每小节仍只一种运镜;**0–3 秒短切/小节照写,不设时长下限,以叙事节奏为准**(不再写 4–8 秒窗口)。
   - 特效要点写到可拍(火星迸开、黑珠激射、云层被犁开),不写抽象渲染词;需要时写明机位与主体的相对方位、同框/不同框纪律。
   - 出场角色一律用库内名称稳定指代,不重复描写外观(外观由设定图参考承担);**角色首次开口的 cut 在 lines 台词前括注声音特质**,如 `(声线沙哑粗粝){泼猴!回头是岸!}`,后续 cut 沿用不再注(零 schema 改动,否决角色库 `voice_note` 字段)。
   - lines 符号规范:台词`{ }`、音效`< >`、音乐`( )`,各占一行;语言统一不中英混排(专有名词除外),生僻字换常用同音字;拼装不解析不强制。
   - 镜头/胶片/质感类关键词(变形宽画幅、胶片颗粒、高速摄影)不进单镜,提议进 IP 画面风格(`set_style`)。
2. **cut 字段零扩**:note/lines 两个自由文本字段装下全部参考图元素,拼装时整段透传;真用下来发现 note 太杂再轻扩(如 `vfx` 字段),留口不堵死。

### D. 链 B 拼装对齐(Q4/Q5 第一轮;Q3 第二轮)

1. `buildCutVideoPrompt` 段序按官方公式重排:画面风格→全片基调→画面描述→景别→运镜→台词/音效→画质约束尾段;空段跳过、全空仍带风格段照旧。
2. **「【画面风格】」段标记换形为「画面风格:」**——躲开官方 `【】` 字幕标记语义(可能把「画面风格」四字渲染成字幕):`canvas.StyleSegment` ↔ `ipStyle.ts` 双侧同形、字面量测试同步、导演判段逻辑(末尾有无该段判已定/未定)与 composer「已含同段不叠」检查同步;70 号票设定图 prompt(`iptask.go BuildSheetPrompt` ↔ `sheet.ts buildSheetPrompt` 同字面量两侧)连带同改。
3. **图N→图片N**:`REF_INDEX_LABEL` 单点改 `'图'`→`'图片'`,绑定行/chip 角标/@ 浮层 token 三处联动(71 号票留的口子,本票收编 E 节遗留验证点)。
4. **画质约束尾段默认硬拼、无开关**:内容「高清,细节丰富,电影质感,色彩自然;保持无字幕,不要生成Logo和水印」单行置尾;要不要背景音乐交给 lines 的音乐`()`段,尾段不写音乐与否;未来要上字幕另票。
5. **生图直通同吃**:`buildCutFramePrompt` 同样前置全片基调段+画质约束尾段(分镜画面是视频首帧种子,同需基调一致与画面干净),两直通口径一致、测试同形。
6. **绑定行形状保守**:只换「图片N」指代,不升级官方主体定义句式(「将图片1中的〔特征〕定义为<名字>」)——等真 key 实测绑定行指代可靠性再议,一次不动两个变量。
7. `cut.seconds` 照旧只预填 duration 参数、不进 prompt 文本;小节秒数由导演写进 note。

## 验证点

- **纯函数单测**(vitest):`buildCutVideoPrompt`/`buildCutFramePrompt` 新段序、空段跳过、基调段(有/无 brief)、画质约束尾段字面量;`ipStyle` 段标记换形双侧;`REF_INDEX_LABEL` 联动(element/presets 测试若钉字面量同改)。
- **Go 测试**:save_storyboard brief 参数往返;导演判段逻辑换形后已定/未定两态;BuildSheetPrompt 同形回归。
- `make test` / `make lint` / `make build` 全绿。
- **真渠道点验**:换形后 Seedance 不再把「画面风格」渲染成字幕(真 key);「图片N」指代与绑定行可靠性(71 号票 E 节一并收);小节秒数写法实测出片节奏。
- **浏览器点验**:编辑层 brief 文本域编辑与回显、直通预填含基调段与尾段、composer 开关关时不误伤基调段。

## Out of Scope

- **主体定义句式绑定行升级**(「将图片N中的特征定义为<主体>」):等真 key 实测,另票。
- **角色库 `voice_note` 字段**:声音特质先靠写作纪律,出痛点再立票。
- **按渠道特判拼装**:维持 71 号票边界。
- **cut 字段拆分**(`vfx`/`scene` 等):留口,note 实测太杂再议。
- **字幕生成支持**(「画面底部出现字幕,内容为…」模板):与无字幕默认约束相反,要上字幕另票(届时尾段需可关)。
- **配乐/音乐开关**:lines 的`()`段已覆盖表达,不做拼装开关。
