# 84 色指定增量(变体配色字段 + 色板模板补色 + 光照色板第六类型)(2026-11-11 grilling 定案)

Type: feat
Status: 定案(2026-11-11 grill-with-docs 定案,06 号一致性深化三项之二;Q5/Q6/Q10 全按推荐;待 implement-spec;依赖 83 号票先行非硬阻塞,仅实现顺序约定)

## Question

70 号票的「色板」只是五类型之一——一张图(模板字面「发色、肤色、服装主色与辅色色块并列」),挂角色变体、**无结构化色值、模板不含光照条件**。研究纪要([ip-methodology](../research/ip-methodology.md))的完整色指定 = 官方色板(发/肤/**瞳/线**色)+ **场景变体**(昼/夜/夕/逆光各一张指定表)+ 逐 cut 检查套用。增量裁三件:结构化色值(能力缺口,现在完全无承载)、模板补色、光照变体;挂点之争(角色 vs 场景实体)按 06 号过程票定案**锁定挂现有 characters 表族**,不预设 04 号 Lore 实体形状——研究纪要里场景变体色指定本就是**角色**在光照条件下的指定表,挂角色侧语义更准;65 号票场景 label(日景/夜景)留作手工锚图承载,场景设定图生成不开(70 号票「另票」口径维持)。

## 定案(2026-11-11 grilling)

### A. 变体配色字段(结构化色值)

1. **挂点**:`character_variants` 双方言加列 `palette`(列名 implement-spec 定,容量 ≥ 500 runes 的 UTF-8 文本)——**变体级单字段**:发/肤/瞳/线色与服装色同字段自由文本承载,换装只改服装色行。**82 号票 migrations 纪律首次实战**:增量脚本成对(`migrations/` 双方言)+ 两侧 EnsureSchema 同步加列 + 形状对账测试绿。
2. **字段语义**:自由文本 HEX 行,如 `发色:#1A2E;肤色:#FFE0D0;瞳色:#4A90D9;线色:#2B2B2B;服装主色:#C0392B;服装辅色:#F5E9DA`(合成示意值);上限 **500 runes**(照 `MaxIPStyleRunes` 先例,超限处理照 69 号票同款口径,implement-spec 定拒绝/清除细节);空值 = 无注入、全链行为逐字节不变。
3. **编辑入口**:资产库抽屉变体表单加配色 textarea(手填);**新建变体时 UI 预填抄当前选中变体的配色值**(纯前端预填,后端不做智能继承——换装改服装色行即可)。
4. **定义通道仅手填**:不做 Agent `set_palette` 工具(69 的 Agent 通道是剧本域「导演提议风格」需求,色值没有对应工作流;要就手填)。

### B. 注入面三链(照 69 风格段模式:固定标记段 + 双侧同形 + 防叠)

1. **五类型设定图 prompt 全拼**(不只色板):`BuildSheetPrompt` 加配色段(变体配色非空时拼;服务端 `iptask.go` 与前端 `sheet.ts` 同形常量,两侧字面量测试互钉);2000 runes 硬截照旧(截断是拼装固定尾步)。
2. **cut 画面直通**:出场角色(cut 绑定变体,83 号票)逐个拼配色——**多角色 = 标记行「角色配色:」+ 逐角色一行 `<角色名>:<配色文本>`,插在绑定行之后**;单角色 = 单行「角色配色:<角色名>:<配色文本>」(照风格段单行形态);无绑定行时落位照 `insertElementLine` 退回首行启发式先例;无配色角色跳过不占行;prompt 已含同段不叠段(照 `ipStyle.ts` 防叠)。
3. **cut→视频无画面注入**:同拼(拼装照 67/73 号票链,配色段插风格段/绑定行之后);有画面路径维持 71 号票不注入。
4. **段不设总截断**:字段 500 runes 已限单角色,多角色行数随出场角色数,单用户自用形态可接受(票面明写,不另设截断);composer 手动模式**不加开关**(要就手写)。

### C. 色板模板补色 + 光照色板第六类型

1. **色板模板字面补色**:「发色、肤色、**瞳色、线色**、服装主色与辅色色块并列」——`iptask.go` 与 `sheet.ts` 两侧同改(字面量测试互钉纪律)。
2. **新第六设定图类型「光照色板」**:`SheetTypeLightingPalette = "光照色板"`,模板 = 同一角色昼光/夜色/黄昏/逆光四格配色对照(同站姿同构图,各格光照差异清晰);`SheetTypes` 固定序插「色板」之后(三视图/多视图/表情集/色板/光照色板/姿态,默认档不变);前端白名单六类 → 七类;双侧同形常量 + 字面量测试。
3. **不进 `ViewLabels`**:`character.go` 的 `ViewLabels = {三视图, 多视图}` 不变——光照色板不计入视图类,封面投影与 70 号票取图优先级行为不变。
4. **场景侧承载否决**:场景设定图生成不开;场景变体色指定 = 角色 × 光照矩阵,挂角色侧(见 Question)。

## 验证点

- 双方言加列 + `migrations/` 增量成对 + 形状对账测试绿;存量行 palette 空 = 全链行为逐字节不变。
- `BuildSheetPrompt` 五类型含配色段、无配色角色不拼段、2000 截断照旧;前端 `sheet.ts` 同形字面量测试互钉。
- cut 画面直通:多角色/单角色/无配色角色三种形状各按 B2;防叠生效;cut→视频无画面同拼、有画面不注入。
- 光照色板:类型下拉出现、生成锚定 label 落库正确、不改变封面投影(既有 `CoverAssetID` 投影测试不破)。
- 配色字段 500 runes 上限生效;新建变体预填抄当前变体值。
- `make test` + `make lint` + 前端 build 三绿 + 浏览器点验。

## Out of Scope

- 场景/道具设定图生成(70 号票「另票」口径维持);场景实体加色指定结构(04 号 Lore 票另议)。
- Agent `set_palette` 工具;Agent 聊天注入配色(52 号票口径不动——配色属变体级,本就不在聊天注入面)。
- 从色板设定图自动反推色值(手抄手填);色值格式解析/校验(自由文本,不判 HEX 合法性)。
- 光照色板进 `ViewLabels`;composer 手动模式配色开关。
