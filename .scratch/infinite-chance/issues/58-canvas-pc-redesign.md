# 58 画布前端 PC 化全面重构(impeccable 改版)

Type: refactor
Status: defined(2026-10-26 grilling 两轮定案,待实现)

## Question

画布前端(canvas/web)以 impeccable 做全面重构。现状三重脱节:DESIGN.md(「深夜工作室」)只是对现状的记录——代码无 CSS 变量、色值全硬编码、z-index 十档(2/4/5/6/10/20/30/90/100/120)散落各组件;CanvasEditorView.vue 约 3600 行巨石,顶栏/横幅/浮层/四侧滑面板/toast 全在一个文件;残留小分辨率兜底(3 处 `min()` 小窗缩窄、2 处 `hover: none` 触屏特判)与「桌面浏览器唯一形态」的定位相悖。定案问题:重构的性质(换世界 / 纯代码对齐 / 保留气质全面改版)、覆盖范围、分辨率基准、代码重构深度、交互行为边界、切票与交付节奏。

## Answer

定案(2026-10-26 grilling,两轮):

1. **性质 = 同灵魂、新躯体**。「深夜工作室」色彩体系与全部 Named Rules 保留并深化;但页面布局、密度、组件质感、信息呈现全面重做——每页当新页设计,不是现状微调。DESIGN.md 随实现修订(修订点见下),不推倒重写。
2. **范围 = 五视图全量**:IP 卡片墙、IP 详情页、画布编辑器、登录、初始化;不允许新旧两种气质割裂。
3. **PC 基准 = 1920×1080 设计基准,1440×900 最低可用**;低于最低可用不做任何兜底(破就破)。删除 3 处 `min()` 小窗缩窄(CharacterDrawer 460 / GenerationComposer 560 / 画布 toast 560)与 2 处 `hover: none` 特判(ImageNode / PrevizNode 触屏下载按钮常显);桌面壳 Wails 最小窗口同步 1440×900。
4. **字号密度 = 维持 11–15px**。「深夜小字规则」不变,大屏的价值是同屏信息量而非字更大;DESIGN.md 措辞补 1920 基准锚定。
5. **改版重心 = 空间 + 质感 + 签名**。侧滑面板加宽(320/340 → 360–400 一族)、顶栏/底栏从容化、画布可视区更大;按钮/输入框/chip/节点卡质感升级,描边玻璃层次与 hover/focus 细节;IP 卡片墙海报感与 11 节点类型色辨识协议强化。顶栏/底栏功能分组重组不在本轮(走白名单通道)。
6. **代码深度 = 呈现层重构**。`style.css` 扩为 token 地基(`:root` 色板/圆角/间距/描边透明度档/阴影词汇/z-index 档位表/过渡 timing,组件 scoped 样式全量换 `var()` 引用);CanvasEditorView 拆组件(顶部栏、alerts、浮层系挂载、四侧滑面板、toast、composer 定位逻辑抽离)。**领域模块零改动**:`graph.ts`/`connection.ts`/`composer.ts` 等 src 根领域模块、`composables/`、18 个测试文件不动;两击连线、生成对话框贴节点定位、灯箱截帧、三个全屏编辑层、面板互斥纪律等交互行为像素级冻结。
7. **行为冻结 + 白名单机制**。默认冻结;重构中发现的 UX 粗糙点(含按钮挪位类)一律登记进本票「白名单清单」,用户逐条确认后才改,不许静默顺手改。
8. **动效 = 基础过渡包**。面板滑入、对话框/灯箱出现、toast、hover 反馈统一 duration/easing(变量化),随本轮做完;编排级动效(连线动画、入场编排)另票。

### 阶段与交付(一张总票,阶段确认制)

- **阶段一 地基(视觉零变化)**:token 地基 + z-index 档位收口 + 过渡变量 + CanvasEditorView 结构拆分;验证 = 测试全绿 + 行为回归点验,截图仅用于确认「看不出变化」。
- **阶段二 画布编辑器改版**:在拆好的组件上做空间/质感/签名改版。
- **阶段三 IP 两页**:卡片墙海报感强化 + 详情页改版。
- **阶段四 收尾**:登录/初始化对齐 + 删小窗兜底与 hover 特判 + Wails 最小窗口 + DESIGN.md 定稿修订。
- 每阶段完成即构建,1920×1080 与 1440×900 双档截图给用户确认后再进下一阶段。

- Layout/响应式段:明写 1920×1080 基准、1440×900 最低可用、低于不兜底。
- 「深夜小字规则」补锚定:11–15px 是 1920 基准下的密度承诺。
- 面板宽度族更新(360–400)。
- 新增过渡规范段(基础过渡包 duration/easing 档位)。
- 阴影词汇与 z-index 档位表的语义注释落 `style.css`,DESIGN.md 引用之。
