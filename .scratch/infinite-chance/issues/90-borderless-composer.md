# 90 生成对话框无边框重设计:填充代描边 + 三段结构重排 + 参数面板化(2026-11-19 定案)

Type: feat
Status: 定案(未实现)。grill-with-docs 四轮定案;参考截图为即梦式 composer 三张(主对话框 / 图片参数面板 / 视频参数面板)。

## Question

用户要求把生成对话框改为参考截图的「无边框」设计。摸底结论:`GenerationComposer.vue`(1539 行,图片/视频两模式同组件)现状是「参考条 → 输入区 → hairline 分组(89 号票)的预估行 + 参数行」三段,参数全是原生 select/checkbox 六件套挤在底行,外框 `1px solid var(--line-control)` 描边 + 双层投影;截图语言是纯填充圆角矩形、无描边、无内部分割线、大留白输入区、底部单行 meta(模型 · 参数摘要 · 成本 · 发送),参数收纳进弹出面板(分段 chips + 比例网格)。

## 定案

- **范围**:仅 `GenerationComposer.vue` 及其定位 composable;AudioNode / AgentNode / VoiceNode 内联表单不动(另一套范式,AudioNode 头注释明说不进生成对话框)。
- **无边框语义**:去外描边(`border: 1px solid var(--line-control)` 清零)+ 去 89 号票 `.composer-foot` 内部 hairline(**89 号票 hairline 分组由本票收编退役**,发送键微动效保留);背景改更实的面板填充,靠色差与画布断开;投影弱化为单层极淡(悬浮层在密集线稿上需一点断开,不全去)。
- **结构级重排**(三段,取代既有三段秩序):
  1. **顶部动作行**:左聚引用类图标钮——「@ 引用」(Q7,点击光标处插 `@` 唤起既有浮层,纯入口增强,不借即梦「智能引用」名)、「+ 上传」、「库」(47 号 AssetPicker,收编为图标钮);右侧「展开」toggle(Q8)。
  2. **大留白输入区**:占位符顶左;textarea `min-height` 64 → 约 120,展开态约 240;**宽度恒 560 不动**,`resize: vertical` 手柄移除(与无边框语言冲突);`useComposerPlacement` 常规/展开两态各估高。
  3. **底部 meta 行**:模型文字下拉(带价展示照旧)+ 参数摘要按钮 + ¥ pill + 圆形发送键,单行收纳。
- **参考条**:保留在对话框内部、输入区上方,chips 形态与全部功能照旧(视频角色切换/元素角标/编号角标/vref-hint/超 4 角色提示行),仅换肤;即梦的对话框外节点预览卡与 ⊕ 不照搬(锚点范式不同)。
- **参数收纳(Q5a)**:模式下拉与参数 select 六件套退役——模型独立下拉;其余收成一个**参数摘要按钮**,文案按当前值实时拼(如 `自适应 / 1K`,视频 `5s / 16:9 / 1080p`;透明附「透明」、IP 风格附「风格」),点击弹出参数面板 popover。
- **参数面板**(形态照截图二/三,参数集是我们现有的——Q10a):分段 chips 族(选中实心)+ 比例网格带形状预览。段序:模式段(顶部,视频节点锁定态照旧禁切)→ 比例网格(档位照旧:图片含 3:2/2:3、视频共享 `RATIO_PRESETS`;「自适应」档位,图片侧照截图二做左列竖块、视频侧照截图三做网格 tile)→ 分辨率通栏分段(按模型分档 `resolutionPresetsFor` 照旧)→ 背景段(仅图片,**仅「自动 / 透明」两档**——「不透明」契约无此值,上了就是 400)→ 带 IP 风格开关行(未配风格不显示照旧)→ 时长段(仅视频)。
- **时长 = 滑杆 + 数字输入组合**(Q11,照截图三):滑杆区间跟随 `durationRangeFor` 按模型收敛、step 1,数字输入失焦夹紧照旧;**「自动」chip 选中 = 不传 `seconds`(滑杆区隐藏),取消自动 = 滑杆出现默认 5s**(裁量补充,保 24 号票「留空 = 不传 = 厂商缺省」语义——滑杆天然有值,必须有自动逃生口)。
- **成本 pill(Q6a)**:独立预估行退役,收进 meta 行 `¥0.36` 形态胶囊——**人民币口径不动**(38 号票全链人民币;积分制不引入),沿用既有预估逻辑,无法预估时整颗隐藏不显示 ¥0,pill title 带原句。
- **不引入清单**(截图有但无领域事实,Q9+Q10):输出图片格式(jpeg/png/webp/gif/svg)、生成质量(自动~最大)、生成视频音频、联网搜索增强、`1x`、底行图标组(人物一致性/提示词优化/超清)、模型 logo 位、对话框上方上传卡;将来真做格式/质量是网关契约 + canvas_tasks 加列 + adaptor 翻译的独立票,UI 票不捎带。
- **行为面零改动**:74 号票节点×模式草稿、发送链与落点、参考守卫(VIDEO_ROLE_CAPS/三类合计 ≤9)、绑定行预览(element-line)、设定图类型 chips、玩法下拉、@ 浮层、禁态条 catalog-error、视频动态占位符(占位文案不随本票改)、27 号票发送后草稿保留、89 号票发送键 hover/active 微动效。

## 裁量与注记

- 参数面板是纯前端收纳新组件;composer.ts 档位表与纯函数零改动,各参数项行为(草稿 sticky/锁定/失焦夹紧)原样迁入面板控件。
- 浮层纪律:面板/Esc 关闭走既有 `onGlobalKeydown` 浮层退栈;@ 浮层锚点随新布局仍贴输入框上沿。
- 中间件安置:提示/预览带(vref-hint、绑定行预览、>4 角色提示)在输入区与 meta 行之间,顺序不变。
- DESIGN.md 回写随实现:无边框协议(填充代描边)+ 89 号票 hairline 分组收编注记。

## Out of Scope

- Audio/Agent/Voice 内联表单换肤;格式/质量参数全链;数量 n(`1x`);积分制;即梦式节点预览卡;普通面板族(AssetPicker 等)的无边框化。
