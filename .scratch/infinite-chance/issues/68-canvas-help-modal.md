# 68 画布帮助浮层(运行总览与生成流程可查)(2026-10-31 grilling 定案)

Type: feat
Status: implemented(2026-10-31 实现;feat/68-canvas-help-modal)。**口径注记**:①内容模块 `canvas/web/src/canvasHelp.ts`(章节数组→块五型:heading/p/list/keys/note,每章末「边界与后续」),渲染组件 `CanvasHelpModal.vue` 只 import 类型与常量、不含任何帮助文案字面量——改文案/加章零组件 diff(结构规范由 canvasHelp.test.ts 守住);②z 档领 `--z-help-modal: 95`(editor-layer 90 与 lightbox 100 之间,style.css 档位表登记);③Esc 在全局栈插在灯箱让位判断之后、其余层之前先收,帮助组件自身不挂 window 监听;④画面槽文案按 FrameSlot 四入口口径(CONTEXT.md「规划节点」条的入口句是 53 号票三入口旧表述,已按组件现状勘误回写,与本票修复同提交);⑤音频运行口径分叉:定案 2 的「图片/视频/音频 = 生成对话框人工发送」**对音频不适用**——音频实际实现为节点内创作态表单人工填写提交(60/61 号票,AudioNode 同音色范式,不进生成对话框),帮助文案照实描述为「节点内表单直发」,以本注记为权威口径。定案背景:2026-10-31 grilling 定案,五问全按推荐;起因:63-67 全链落地后两处预期差——剧本节点没有「下一步」、画面槽没有「生成」,运行模型无处可查;**流程本身未完全定型,后续还要优化,内容必须好改**——用户特别要求

## Question

剧本全链(63-67)落地后,「哪类节点怎么运行」「流程下一步是什么」「哪些能力是二期」全部靠口头交流;画布内没有任何帮助机制(仅工具栏底部快捷键提示文案)。需要一个画布内可查看的帮助浮层承载运行总览与生成流程,且内容层与组件分离——流程未定型,后续修改只动内容不动组件。

## 定案(2026-10-31 grilling)

1. **居中模态浮层**:Teleport 到 body、Esc 关闭、z 坑位沿用灯箱族纪律(MediaLightbox 同族范式),内容区滚动,只读文档;编辑层/灯箱开着时 Esc 逐层退出栈让位(38 号票窗口级快捷键纪律)。
2. **帮助骨架 + 首版两章**:「① 节点与运行总览」(图片/视频/音频 = 生成对话框人工发送;Agent = 对话驱动工具循环;剧本节点 = 被动载体不连线;絵コンテ = cut 编辑层,画面槽四入口/直通)+「② 剧本流水线全链」(list_assets 对表→先选后展 2-3 方案→大纲/逐集剧本/分镜落图→cut 配画面(挑选/上传/落图/直通生成)→cut→视频直通人工发送);骨架可扩展加章,后续新章不问形态只写内容。
3. **零依赖内容模块(内容与组件分离是硬要求)**:TS 结构化常量(章节→块数组:标题/段落/要点列表/键位/边界注记),单一内容文件(如 `canvasHelp.ts`)+ 薄渲染组件;**改文案/加章只动内容文件**,组件不感知具体文案。不引 markdown 渲染依赖(单用户 YAGNI)。
4. **入口双通道**:底部工具栏动作区「?」按钮(与素材库/生成记录/上传并列)+ 快捷键 `?`(Shift+/);window keydown 监听,输入框/textarea 聚焦时不触发(38 号票键盘纪律守卫同款)。
5. **边界注记**:流程步骤旁标实现现状;章末固定「边界与后续」小节(出场角色→生成注入 = 二期;cut 批量生图/生视频 = 三期;台词→TTS = 三期;真渠道 tools 透传实测 = 部署欠账)。帮助 = 单用户自用备忘,写明边界防预期差。
6. **术语与文档纪律**:文案用词严格按 CONTEXT.md(剧本节点/絵コンテ/画面槽/生成对话框/直通/角色对表);本功能纯 UI 文档、无新领域概念——**不新增 CONTEXT.md 词条、不需要 ADR**,形态语义以本票为权威。

## 验证点

- 浮层开关链:按钮/快捷键开、Esc 关;与灯箱/编辑层同开时的 Esc 让位顺序(help 在栈顶先收)。
- 两章内容与真实控件逐条对账——帮助里描述的每个按钮/入口都能在画布上指到。
- 输入框/textarea 聚焦时按 `?` 不触发浮层;浮层开着时输入不受影响。
- 结构性验证:改一条文案、加一章,只动内容文件,渲染组件零 diff。

## Out of Scope

- markdown 渲染器;帮助内容的在线编辑/远程下发;i18n。
- 节点空态内嵌引导(onboarding 提示、首用向导)。
- admin-web 侧帮助(网关管理面不在本票)。
- 截图/视频教程(纯文字首版);帮助访问统计(单用户无意义)。
