# 28 生成记录面板:画布内任务流水可查、产物可找回

Type: grilling
Status: approved（2026-09-30 grilling 定案,待实现）

## Question

「生成了之后找不到」:`canvas_tasks` 自 10 号票起就持久化每次生成的完整流水(prompt、模型、size/ratio/seconds、状态、失败原因、asset_id、时间),按画布查任务的 API 也现成(`GET /canvases/:id/tasks`,新到旧、上限 200),但没有任何 UI;失败任务节点一删,界面上痕迹全无。生成记录模块放哪、长什么样?

## Answer

1. **定案(方案 A):画布内「生成记录」侧滑面板**——与素材面板同款交互范式,工具栏加入口,列**当前画布**的任务流水(新到旧)。管理台全局生成记录页(方案 B)显式不做:离创作动线远,素材页已覆盖「全局看产物」的一半需求,将来真有审计诉求再另立票。

2. **数据零后端改动**:直接消费既有 `GET /canvases/:id/tasks`(taskJSON 含 id/kind/prompt/model/size/ratio/seconds/status/error/asset_id/image_url/video_url/created_at/updated_at)。端点无 offset 分页、上限 200 条——MVP 接受:面板顶部注明「最近 200 条」,量级超限的梳理诉求归将来(需要时端点加 offset,不构成本票前置)。

3. **行内容**:缩略图(成功行走素材 content 地址;失败/取消行按 kind 显示图标徽章)、kind 徽章(图片/视频)、提示词截断可展开、模型名、状态、时间;失败行内联显示 error 摘要。

4. **行为**:点记录 → 绑定节点仍在图内则画布平移定位并选中该节点;成功记录的节点已被删、或想在画布上再放一份 → 行内「插入画布」按钮,复用素材面板的插入语义(asset_id + `/api/assets/{id}/content` 内容寻址,不复制字节);素材行也已删 → 该行显示不可用占位、无插入按钮。**不做面板内重试/取消**(节点卡片已有,记录面板保持只读 + 定位/插入两个动作)。

5. **显式 out of scope**:按状态/类型过滤(MVP 不做,列表量级单用户可控);跨画布聚合;失败行在面板内重新提交。

6. **验证点**:任务绑定节点被删后 `node_id` 悬空的行,定位动作静默降级为无操作(不报错);200 条截断下新到旧的排序与任务轮询刷新不打架(面板开着时新任务完成后行内状态就翻成 succeeded)。

7. **产出面**:`canvas/web`(新面板组件、编辑器工具栏与接线、复用 `@infinitechance/api` 既有类型);CONTEXT.md 新增「生成记录」词条。
