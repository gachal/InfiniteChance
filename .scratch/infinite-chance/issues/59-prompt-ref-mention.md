# 59 提示词 @ 引用(参考图选择浮层)

Type: feat
Status: implemented(2026-10-27 实现;浮层开合 = 「光标前一字符是 @ 且有可引用条目」一条判定同时承担触发与保活——继续输入/移走光标即收,Enter/Tab/Esc 的 keyup 不重判防弹回;Agent 浮层只收就绪附件,上传中/失败的 chip 无可引用素材故不进列表也不编角标)

## Question

图片和视频节点的提示词需要 @ 功能:输入 `@` 后显示「对应添加的参考图」的选择列表,选中即引用。grilling 中扩展:Agent 节点输入框也要做同款。

事实底座(2026-10-27 调研):参考条 chip 目前无编号无名称(只有缩略图),用户「对号入座」全靠数;22 号票已定案「`image` 数组顺序即参考序,提示词『图N』按下标对应」,且该顺序从前端参考条 → `image_urls`/`video_refs` → 网关 → VOD/Ark/MiniMax/DashScope 全链路原序不变——@ 插「图N」式 token 有契约直接背书,但前端尚无对应物。弹层范式现成:AgentNode 的 `/` 技能浮层(触发检测 + ↑↓/Enter/Esc 键盘导航 + IME 让位 + `mousedown.prevent`)已被 31(技能)、52(角色)两轮复用。改动面:生成对话框是 `GenerationComposer.vue` 单组件(两模式共用)、参考条数据经 props 传入,Agent 输入框在 `AgentNode.vue`——本功能可完全收在组件层,不动 `composer.ts` 等领域模块(58 号票冻结物)、不动后端。

## Answer

定案(2026-10-27 grilling 三轮):

1. **功能定义**:生成对话框(图片/视频两模式)与 Agent 节点输入框的提示词 textarea 中,光标处输入 `@` 弹出「当前上下文已添加媒体」的选择浮层,选中即在光标处插入引用 token。Agent 节点纳入(用户定案)。

2. **@ 对象与编号口径**(按上下文三态):
   - **图片模式**:参考条全部条目(含自动入条的选中节点产物 chip),`@图1..@图N`,N = 参考条顺序。
   - **视频模式**:仅「参考图」角色条目可 @,`@图1..@图N`,N = 参考条中参考图条目的顺序;首帧/尾帧/参考视频/参考音频**不进列表**——与 `references` 契约序严格对齐(首帧走单串 `image`、尾帧走 `last_image`,不占 references 序;44 号票「首帧切参考图」场景下编号不漂移)。
   - **Agent 节点**:当前输入的**附件 chips**(不含会话历史媒体——历史媒体随轮滚出、编号不稳定,列进去列表又长又对不上号),图片 `@图1..@图N`、视频 `@视频1`,按各自插入序编号;token 随消息历史固化,模型按文本所在轮就近理解(「发那轮的第 N 张图」)。Agent 收视频附件是用户对口径统一性的显式取舍(Agent 走聊天模型无上游编号契约,收视频零成本;与 composer「仅参考图」不一致被接受)。

3. **token 语义 = 纯文本**:插入 `@图N`/`@视频1` 字面文本,与 22 号票「顺序即参考序」契约同构;**悬空引用不校验不警告**(参考被移除后编号自然前移,与上游语义一致——@ 的价值在「选得准」而非「校得严」);同一参考可重复 @;未选中就关闭时 `@` 留作普通字符。发送、落结果节点、草稿保留(27 号票)、生成记录链路零改动(token 就是提示词文本的一部分)。

4. **列表与角标**:浮层条目 = 缩略图 + token 文案(composer 视频模式加角色标签,Agent 视频条目用视频徽章样式),缩略 URL 走现成 `useThumbFallback`;**chip 编号角标**一并做——composer 图片模式参考条、视频模式参考图 chip、Agent 图/视频附件 chip(视频角标「视频1」),@ 列表与 chip 编号互相印证(没有角标,@图N 对用户就是黑号)。

5. **交互包**(整体仿 `/` 浮层范式):
   - 触发:光标处输入 `@` 即弹(任意位置,不限行首——`/` 限定行首是技能语义,@ 不需要);列表常显全部可 @ 条目,**不做文本过滤**(条目最多 9 个,过滤价值低,省掉 @ 后文本积累的删除逻辑)。
   - 键盘:↑↓ 移动高亮(循环)、Enter/Tab 选中插入、Esc **仅关浮层**(composer 里不波及对话框关闭链——全局 Esc 链对 `isTypingTarget` 已让位;Agent 里不清输入——`/` 浮层「Esc 清输入」的既有行为不互改);浮层开着时 Enter 归浮层、不触发发送;IME 组词中让位(`isComposing` 同款)。
   - 鼠标:列表项 `mousedown.prevent` 防失焦、点击即插入;点击浮层外关闭。
   - 插入动作:替换光标处的 `@` 为 token,光标停 token 后。
   - 定位:浮层贴 textarea 上沿左对齐弹出,**不做光标像素级跟随**(mirror-div 测量成本不值得)。
   - 边界:参考条/附件为空时输入 `@` 不弹层(普通字符);Agent 输入框内 `/`、`@`、角色三浮层互斥、同一时刻只开一个、后触发者优先;触发判定 = 光标前一字符是 `@`。

6. **实施形态**:59 号独立票,当前在 main 实现(58 号票阶段一已完成、阶段二未开始;58 的「行为冻结 + 白名单」管的是重构不许改行为,不拦新功能票)。改动收在组件层(`GenerationComposer.vue` + `AgentNode.vue`)+ 新增纯函数模块(编号派生 + token 文案,独立 vitest);**不动** `composer.ts`/`graph.ts` 等 58 冻结领域模块、不动后端与网关契约、不动 `packages/`。58 阶段二编辑器改版时,新浮层按当时 token 地基顺路重着色(行为已冻结落地,改的是质感)。

## 验证点

- 三上下文编号口径:图片模式全条目 1..N(含节点产物 chip)、视频模式仅参考图角色编号、Agent 图 1..N + 视频1;chip 角标与浮层编号一致。
- 键盘全链:↑↓ 循环、Enter/Tab 插入、Esc 仅关浮层(composer 对话框不关、Agent 输入不清)、浮层开着 Enter 不发送、IME 组词中不触发。
- 悬空场景:插入 `@图3` 后移除图 3,发送不警告不拦截(纯文本语义)。
- 边界:空参考条/空附件 `@` 不弹层;重复 @ 同一参考;点浮层外关闭;`mousedown.prevent` 不失焦;三浮层互斥后触发者优先。
- 回归:composer 发送链路(草稿保留、落结果节点、生成记录面板 prompt 展示)、Agent 发送/投递、`/` 与角色浮层不受影响。
- 新增 vitest 全绿 + 既有 18 文件全绿 + `pnpm --filter canvas-web build`(vue-tsc 含内)+ `make lint` + 浏览器点验。
