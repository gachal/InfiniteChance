# 39 预演台:三维 previz 节点(静帧排练 MVP)

Type: grilling
Status: implemented(2026-10-05 实现;2026-10-05 grilling 定案,七问全收口)

## Question

创作线(尤其生视频)贵且慢,构图/机位/站位错了再改就是真金白银重烧。需要「正式拍摄」前的免费排练手段:在画布上模拟三维场景,提前可视化与排练——拍摄前把剧本、分镜、机位运动、虚拟场景先做一遍低精度或实时预演(用户原话)。本票切第一刀:静帧排练 MVP。

## Answer

1. **核心语义 = 三维 previz(Q1)**:预演台是第五种节点类型,「提前可视化与排练」。单用户 AI 生成画布语境重述:导演/摄影/特效都是用户自己,「正式演出」是花钱的 AI 生成。否决读法存档:低成本彩排小样、零成本干跑试算、AI 批量分镜故事板、素材拼合 previz(2D)。

2. **预演帧归宿 = 喂 AI 生成链(Q2)**:3D 摆台 =「免费彩排」,AI 生成 =「正式拍摄」——渲染帧(零计费)落素材/节点后作为参考图喂图生图、或首帧喂图生视频。否决独立预演工具(不接生成链,与「画布即工作台」相悖);AI 反向预演(批量分镜)另票。

3. **MVP = 静帧排练(Q3)**:场景 = 地面 + 基础几何道具(盒/柱/板);角色 = 内置人形代理(平移/旋转/缩放,不做姿势);机位 = 多机位(位置/朝向/焦距 FOV);光照 = 固定默认光;输出 = 当前机位渲染静帧 PNG。机位运动(关键帧时间线)与剧本/分镜表管理记 out of scope 另票——喂 AI 的参考图/首帧本就是静帧,构图锁定已覆盖价值大头。

4. **资产 = 内置极简代理(Q4)**:人形素体(站姿,真人比例)+ 基础几何体随组件内置,零外部资产文件。glTF 导入管线(加载/体量/许可)另票排队;AI 贴图/升格不另做(Q2 闭环已覆盖:渲染帧喂生图即美化)。

5. **场景数据随节点 data 存整图 JSON(Q5,按先例默认)**:对象列表 + 机位列表,27 号票「数据随身」、32 号票会话历史同款先例,自动保存免费获得,不建新表;MVP 几十个代理对象体量可控。

6. **渲染帧归 `uploads/` 档(Q6)**:复用 `/api/assets/upload`(前端 WebGL 画布 `toBlob` 后上传,零后端改动),键落既有 `uploads/{yyyymmdd}/{uuid}.{ext}`;预演帧与用户上传同义(用户创作媒体),不新增 `previz/` 前缀、不动硬性约束 7 三分归档。审计辨识:`kind=image` + 无 canvas/task 归属。

7. **节点形态 =「媒体区 + 落画布」(Q7)**:节点卡片带媒体区展示**最新渲染帧**(可点灯箱,33 号票组件「留口待挂入口」在此兑现),节点内显式「渲染」动作出帧;媒体区旁「落画布」按钮把当前帧落为**新图片节点并连线**(复用产物落位+连线语义,可多次,每次渲染的帧各自成节点)。喂生成链一律经图片节点进对话框参考条/首帧——**生成对话框不认预演台节点**,参考条/计费生态零改动。连线矩阵新增第五种合法边 **预演台→图片**(渲染帧落点);预演台不作任何连线的目标(输入是用户摆的场景,不接上游)。渲染不走 `canvas_tasks`(本地 WebGL,无任务行),不进生成记录面板。

## 显式 out of scope

机位运动/关键帧时间线(Q3-B);剧本与分镜表管理(Q3-C);姿势系统与骨骼;glTF 导入与材质贴图;AI 贴图/升格;多机位批量出帧;渲染帧进生成记录面板;预演台场景协同(单用户不存在)。

## 产出面

- `canvas/web`:`three.js` 依赖;`PrevizNode.vue`(3D 视口 + 代理摆放 + 机位控制 + 渲染/落画布);previz 场景数据类型进节点 data;连线轻校验矩阵加 `previz→image` 边、预演台不可作目标;工具栏添加入口;灯箱挂预演台媒体区(33 号票留口)。
- `packages/api`:节点 data 类型扩展(previz 场景/机位)。
- **后端零改动**:`canvas_tasks`、网关、素材上传链原样。

## 验证点

渲染帧 PNG 正确落 `uploads/` 档素材且可预览/灯箱;落画布 → 图片节点 → 对话框参考条/首帧全链;连线矩阵拒绝非法方向(预演台作目标、其余反向);场景数据随整图 JSON 自动保存(刷新不丢);`make test` + `make lint` + 前端构建 + dev 实际点验。
