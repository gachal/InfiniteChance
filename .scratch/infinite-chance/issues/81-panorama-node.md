## Question

画布缺「空间感」载体:用户添加一张图(**不一定是全景图**),节点生成相关场景的 360° 全景,点击打开后网页内 720°(水平+垂直全球面)环绕查看。shuo-canvas 调研曾把「360° 全景」判为被预演台覆盖、21 号票曾以「网关无对应能力不虚设入口」搁置全景入口——本票推翻两条旧判定,独立立项。

## 事实底座(2026-11-06/07 调研;`[实测]` = 真 key 探针实证,过程见「打样记录」)

- **代码底座**:three.js 0.186.1 + OrbitControls 已在(预演台 39/40 号票)——球面查看器**零新依赖**;预演台的 OrbitControls 限俯仰不越地平线,全景不能照搬。节点注册(graph.ts 五处 + 编辑器插槽)、右键菜单条目、`EDGE_MATRIX`、帮助浮层、`NODE_TYPE_LABEL`、minimap 配色清单齐备(创作菜单条目数测试现钉 `[10,4,1,4]`)。画布图片任务只传 size 像素串不传 ratio;VOD adaptor 把 size 就近吸到 6 档 AspectRatio(无 2:1);直通生成 `spawnProductNode` 与产物回填 `mediaSyncPatch` 现成。查看器贴图走 `/api/assets/{id}/content` 同源代理(26 号票读兜底)——无 CORS 问题,截图导出不受画布污染。

- **备选存档**:Panorama API(第三方:照片转全景,1K/2K/4K 恒 2:1,4/6/10 credit,Pro $19.9/月起、credit 月结转)——有原生不接第三方;自托管 HunyuanWorld(~26GB)/1.0-Lite(~24GB)/DiT360(~37GB)VRAM 全超 4060 8GB,排除。
- **计价现实**:og-image-2.5 库内 0.05 元/次为 20 号票占位价,实价 = 1K 0.036 / 2K 0.080 / 4K 0.100 + 参考图输入 0.1 元/张;**VOD adaptor 无 4K 档**(长边 ≥2048 恒判 2K,21 号票遗留)——SIZE_TABLE「4K」档尺寸腾讯实际按 2K 计费。

## 定案

1. **通路**:主通路 = 腾讯原生全景(VOD 域),公开名 **`hunyuan-world-panorama`**(model_map → `Hunyuan 3d_2.0` @ 现有 tencent-vod 渠道,公开名即调度单元);**OG 生成全景淘汰**(接缝不达标);**ExtInfo 自由分辨率翻译另票**(服务普通生图 21:9 等,收编 37/21 号票遗留);第三方服务与自托管不接(存档本票)。
2. **术语与节点**:第 14 种节点类型 `panorama`,右键「创作」段第 11 条,UI 名「全景」,卡与查看层带「360°」角标;产物素材行恒 `kind=image`,全景语义只活在节点层。
3. **网关契约**:`/v1/images/generations`(JSON)与 `/v1/images/edits`(multipart)加**可选 `scene_type`**(当前仅收 `"3d_panorama"`,其他值 400;缺省不传 = 现状逐字节不变);openai 型渠道照 `background` 先例全量透传不剥离;vod adaptor 见到即在 `CreateAigcImageTask` 带 `SceneType`(打样已证 SceneType+Base64 FileInfos 组合受理);**prompt 豁免只在画布层**(网关本就不强制 images prompt;画布 createInput 的「prompt 不能为空」对 `scene_type=3d_panorama` 形态放行);n 恒 1。
4. **schema**:`canvas_tasks` 双方言加列 **`scene_type`**(VARCHAR(32)/TEXT,空 = 普通生图;37 号票 `background` 列范式;SQLite 加列先于索引建);worker 两路(`ImageRefs>0` 走 edits、否则 generations)显式携带;任务 JSON 回显 scene_type,生成记录面板出「全景」徽章;全景任务行 prompt 恒空串(上游不吃)。
5. **画布面**:创作态表单 = **参考图 chip 必填恰好 1**(上传 + AssetPicker 双入口;chip 旁注记「须为场景图,人像/物体会被上游拒绝」)+ **模型下拉**(`/image-models` 全量、缺省 `hunyuan-world-panorama`、不按模型特判——选非全景名由上游 400 透出)+ 生成按钮;**无描述框、无尺寸/比例/透明选项**(上游固定 8K 2:1;原生不吃提示词,Q3/Q10/Q11 的描述与尺寸定案随之作废)。内联表单是 ADR 0002 的显式例外(理由:全参数固定,进对话框等于全禁用控件;音频系同族先例)。产物回填节点自身(`PanoramaNodeData` 配对 `{ref_asset_id, url, asset_id, model}`);**重新生成 = 原地替换**,旧产物留素材库。节点**不参与任何连线**(不作源不作目标)、**选中不唤起生成对话框**;卡面不跑 WebGL(2:1 缩略 + 360° 角标,40 号票纪律)。
6. **直接环视**:创作态参考图(或素材库任意图)宽高比 ≈2:1(±2%)时出「直接环视」按钮——不生成、不花钱直接进查看层(覆盖「参考图本来就是全景」与「素材库全景图再看」两场景)。
7. **查看层**:独立全屏浮层(编辑层范式,Teleport 单实例,z 90 族,Esc/返回退出),three.js 球面贴图 + OrbitControls(**全俯仰**、阻尼;预演台的地平线钳制不照搬);贴图源 = `/api/assets/{id}/content` 同源代理;入口 = 产物态整卡点击(创作态整卡即表单不进查看层)。
8. **截图(查看层内)**:取景框比例可选(1:1/16:9/9:16/4:3/3:4,缺省 16:9,复用 RATIO_PRESETS 家族)、长边固定 1920;导出 JPEG 经 `/api/assets/upload` 落 `uploads/` 档挂画布 IP;**仅进素材库不落节点**(Q8 定案,理由:连拍多角度不堆画布;要用经素材面板/参考条「库」入口取);连续截不关层,toast 确认;按钮 + 快捷键(实现裁量,注意与灯箱 S 键分层)。
9. **产物校验提示**:产物宽高比偏离 2:1 超 2% 时卡面提示行,照常可看可重生成;帮助浮层补全景节点章与菜单文案;右键菜单条目数测试同步(`[11,4,1,4]` 族);IP 风格不注入(参考图自带风格,另票再议)。
10. **计价与配置(2026-11-07 已随定案经 admin API 落地并回读核对)**:①`hunyuan-world-panorama` call 轨 **5 元/次**(两份计费页一致;账单核后校准);②`og-image-2.5` 实价重配 = 基价 0.036 + 10 个 2K 档尺寸键 ×2.2222(系数键 = 字面 size 串;VOD 无 4K 档故 4K 表尺寸实按 2K 计——补 4K 支持时调 2.7778,21 号票遗留);③渠道 4 model_map 增 `hunyuan-world-panorama`(config 凭据未动,连通测试 ok);④参考图输入费(0.1 元/张)网关契约不单列,少记注记在案。
11. **文档回写(实现时执行)**:CONTEXT.md 渠道词条(VOD 场景类型透传)/生图转发词条(scene_type 契约)/素材词条零改动;docs/api.md 补 generations/edits scene_type 用例;无 ADR(单 adaptor 参数透传,可逆,打样记录即决策依据)。

## 验证点(实现后真机,按序)

1. 网关链路端到端:公开名经 `/v1/images/edits`(multipart scene_type)全链出 8K 全景——打样走的是直连探针,adaptor 翻译与 generations/edits 两路解析仍需实现后复核。
2. 查看器:8K 贴图(7680×3840)在浏览器与 Wails WebView 的性能/内存;必要时查看器侧降采样(实现裁量)。
3. 极点与接缝在查看器实际观感(重投影已预验 0.022)。
4. 上游拒绝文案透传:人像/物体参考的场景审核(MPS 域实测原文)、合规拦截、把 scene_type 打到非全景公开名的 400。
5. 账单:打样两张(OG 4K 档 + 原生全景档)的实际计费,校准 5 元配价;2K/4K 档位计费与系数表核对。
6. 截图链:五档比例导出 → 上传 → 素材面板可见、可作普通参考图。

## Out of Scope

- OG 全景生成(接缝 0.315 淘汰;产物图仍可当普通 2:1 图用)。
- ExtInfo 自由分辨率翻译给普通生图(另票,收编 37/21 号票遗留,含 ≥4096→4K 档)。
- 第三方全景服务(Panorama API 等)、自托管 HunyuanWorld/DiT360(VRAM 排除,存档)。
- MPS 域全景通路(mps adaptor 生图是桩;「VOD 收下不执行」类域陷阱已由打样排除——VOD 域真出全景)。
- 热点/多场景漫游串联、文生全景(无参考)、视频天空盒、立体声、IP 风格注入、查看器内二次生成(取景截图 → 生成链走图片节点既有路)。
- 21 号票「4K 在 VOD 归入 2K」的 adaptor 补全(随自由分辨率另票)。
