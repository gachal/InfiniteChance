# 生成类操作收敛到对话框,节点回归产物展示

画布的生成操作最初长在节点上——提示词节点带生图表单、图片节点带图生视频/分析
表单——节点既是产物又是操作面板,多节点时界面膨胀、同一组模型/参数状态分裂在
多处。21 号票起改为「生成对话框」范式:单实例悬浮 composer 跟随选中节点(未选中
时停靠画布底部中央),选中即上下文(其产物成为参考图),生成类表单收敛进对话框;
节点回归产物展示。以混合式过渡而非一步到位:提示词节点的生图按钮保留,其产出的
图片节点即新形式节点;图片节点上暂留的图生视频/分析表单待视频票收编——先把最高
频的图片生成链(文生图 → 选中产物 → 图生图迭代)走通新范式。

## Considered Options

- **两套并存**(对话框与节点表单都留):同一件事两个入口、参数状态分裂两处,放弃。
- **每个节点内嵌 composer**:视觉噪音与重复参数控件随节点数线性膨胀,且截图原型里
  只有选中那张图带对话框,放弃。
- **只换生图链路**,分析/反推/图生视频留在节点:范式落地一半,作为本票范围裁剪的
  现实选择接受(视频票收尾),不作为终态。

## Consequences

- 后续视频/分析票沿同一模式盖楼(对话框底栏模式下拉预留位),改动成本随时间递增;
  回退窗口在视频票落地前最便宜。
- 提示词节点保留旧生图按钮是刻意的过渡态,不是遗漏;后续读者不要把它当 bug
  "修掉"(21 号票定案)。
- composer 单实例的选中绑定与草稿状态集中在编辑器层,节点组件不持有生成参数。
